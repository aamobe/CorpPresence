## 清理内容

六台机器定点合并顶盖、接头、机壳的近似色与孤立亮点，减少重复亮边；保留筛孔、双辊、仪表、液面、管路与结构边界。粉末工艺素材统一板边、金属接点和工艺台连续平面，两帧共同区域同步修改。矿柱仅合并少量碎色，保持竖状轮廓；光盐芯两帧经检查无需修改，原像素完整保留。

生成式清理尝试未保持原生画布，未作为交付精灵或缩小输入。最终PNG均由原生可编辑像素矩阵上的局部修整导出。可复现脚本为上级目录 `Clean-Native-Batches.ps1`。
