## 原图观察

### 视角与结构

机器净水器是 `purifier`，48×64，主体包围盒 `(2,3)–(45,62)`；便携净水器是 `portable_water_purifier`，32×32。旧规范链接错了，也遗漏了前者的三根长筒与完整支架。

`purifier` 与 `furnace` 主要正面边缘水平、竖直；顶部、管筒端面、上缘倒角和浅侧缘提供俯视深度。正前上方观察与正前上方受光是两项独立条件。无需把整机左右旋转成三分之二侧视，也不能仅给平面图加一条侧边。`gibber`、`blender`、`heating_plate`、`ras` 的椭圆开口和前后遮挡更明确；`animal_cage` 顶面较宽。顶面占比按具体参考和功能确定，不能一律放大。

功能识别来自大部件关系：净水器的筒体、炉子的门与格栅、搅拌器的上下支撑、RAS 的槽与旁置模块。左右对称并非统一要求，DNA 设备、RAS 和喂食器都有不对称功能布局。

### 色块、光泽和过渡

`furnace` 主体仅 9 色，`purifier` 16 色，`printer_off` 26 色；“每机固定色数”不能概括原版。原图的深紫轮廓、灰紫中间层、灰蓝金属与暖灰浅面共同形成风格。色相变化必须结合具体材质、邻接关系和面积，不能把全机灰色整体映射为紫色。

| 原图 | 实测 RGB 与主体像素数（节选） | 可观察用途 |
|---|---|---|
| furnace | `303A41` 400、`292234` 392、`C4C4B0` 367、`80929B` 299、`777081` 270、`D5D2B8` 95 | 深色舱口、紫暗边、浅色顶壳与灰蓝过渡并存；不是单色等距提亮 |
| purifier | `292234` 524、`6B5269` 406、`275654` 388、`80929B` 287、`303A41` 194、`2F756F` 158 | 支架与筒体使用不同色组；筒体纵向明暗服从圆柱形体 |

这些计数来自 Alpha≥128，不把导出背景的 Alpha=1 算成材质。色板按面积排序不代表色阶顺序，取色必须同时看空间分布。金属反光可用多色段，但不是每条边必须多色；玻璃斜反光也不能泛化成所有金属的45°条纹。

原图内部存在很深的舱口、边框、缝隙和部件分隔。“最深色只准出现在透明边缘”会破坏结构。曲面、斜面和圆角依部件尺寸组织像素，不应强制所有斜线仅角接或所有圆角使用同一数列。

## 已修订的问题

| 原要求或缺口 | 修订 |
|---|---|
| 净水器链接指向便携物品；旧 MOD 机器永久作为主参考 | 明确 purifier／furnace 为本次六台机器的视角参考；旧稿仅在用户要求沿用时读取 |
| 光照45°、俯视角与侧视混在一起 | 分别记录观察方向、顶面深度、光照；不声称有测得的相机角度 |
| 暗部必须同色相，每材质固定3–4阶 | 按原图材质色组、色相变化、面积和邻接关系取色；色数仅预算 |
| 内部禁止深描边、圆角固定数列、统一45°短条 | 改成有结构依据的深边、台阶与反光 |
| 禁止任何预览，同时要求1×／4×检查 | 原生图为交付物；用户对照与必要诊断允许同倍率整数最近邻，不替代原生验收 |
| 提示词强制四边至少3像素留白 | 按目标包围盒、锚点和占格填写；furnace 原图边缘只有1–2像素，不能机械缩小主体 |
| “重新设计”仍可沿用旧稿的轮廓和布局 | 从功能需求重新定轮廓与部件组织；不载入被排除的旧生成稿或旧绘图坐标 |
| 以尺寸、原版RGB、二值Alpha通过推断风格通过 | 技术检查与视觉审查分别记录；审查视角、部件关系、色块面积和原生辨识度 |

规范问题会诱发偏差，但先前没有按用户指定的参考和重新设计范围执行，也是执行问题；修订文档不能替代下一次实际看图审核。
