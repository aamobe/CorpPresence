# 美术维护入口

完整资料已整理到[深空当铺美术目录](README.md)。开始制作、修改、缩放或导入前，先读[总规范](AGENTS.md)，再按[人物](PORTRAITS.md)、[物品结构与材质](STYLE-REFERENCE.md)、[缩放与防杂色](SCALING.md)分流。下文保留简要维护说明。

游戏内PNG位于[src/Assets](../src/Assets)，以项目`EmbeddedResource`嵌入。文件名如`CorpPresence.art.solana.perfume_mixer.png`同时参与资源查找，不能只改文件名而不查调用。

## 分类

| 类型 | 维护重点 |
| --- | --- |
| 物品与机器 | 原生尺寸、库存占格、调色板、外轮廓、材质明暗与Alpha |
| 运行状态差分 | 从同一母版派生，共享画布、原点和不变区域 |
| 植物状态 | 检查`_p`/`_p2`映射、多年生再次结果和实际显示 |
| 人物立绘 | 使用人物自身的构图与显示参考；不套物品16像素库存规范 |
| 宣传横幅 | 与游戏精灵分开；生成大图不得当作已验收原生精灵 |

公司人物立绘以游戏原版的显示适配为基础，以撒该风格分析为主要标准；不沿用物品缩小和限色方法处理人物。

## 物品和机器

先确认游戏原生尺寸与占格，选同用途原版参考。参考自身RGB和材质明暗，平面用连续色块；不要通过“高分图缩小再限色”宣称已经原版化。生成工具重绘的相似区域不能叫像素保留。

缩小后的防杂色检查必须在最终尺寸进行：机壳、顶盖、瓶身与底座应保持连续主色和清楚折面；随机近似色、无用途孤立亮点和破碎阴影要修整。指示灯、铆钉等有明确结构作用的像素保留。检查1×和4×最近邻预览，记录仍待验证项。

光源以前上方45°为准，倒角亮、竖侧面暗、底部与脚最暗；大平面不加随机噪点。外轮廓与内部结构用不同层次，玻璃优先用色块与反光表达，不随意改变整层Alpha。

## 状态与导入

差分要比较公共区域RGBA，主体和透明轮廓不得漂移。PNG尺寸、PPU/pivot、库存占格、点击区域和状态切换需要分别检查；不能靠透明留白替代占格定义。原版图集的mipmap和模组独立贴图的方案分别处理。

素材记录至少包含来源版本、尺寸、Alpha、改动区域、缩放过程、静态预览和运行时验证状态。仅编译通过不能写“画面已验证”。

游戏正式素材仍以`src/Assets`为准。美术资料目录收录的是固定参考、测量和规范，本次资料上传不更换游戏素材，不把未发布罗森改稿或宣传图加入运行时发布基线。
