## 甲板酒和引擎酒

勾兑酒的核心是处理成分各异的回收原液。拿到一批酒液后先检测，决定是加水直调，还是先去除一类指定杂质再回配。荧光莓只负责少量风味和可喂食的果渣砖。努特加作为成分稳定的基酒用于校准。

| 酒体 | 试验工序 | 玩家取舍 |
|---|---|---|
| 甲板酒 | 检测普通基酒或低杂质回收液 → 补水和风味 → 点击调和 | 水会同时稀释酒精与风味。 |
| 引擎酒 | 检测高杂质回收液 → 借相邻反应堆余热处理 → 重测并回配 → 点击调和 | 处理降低一种指定杂质，建议同时损失部分可用酒液。停机时需先修反应堆，或换原料做甲板酒。 |

这是拟议路线。甲板酒和引擎酒与现有风味酒、浓莓烈酒的命名及配方对应关系待定。首轮建议用两种回收液、一次前处理和一款可复现的成品验证玩法。回收来源、指定杂质、去除率、液量损失和设备形态待定。

旧版原版 `ReactorHelper` 中，简易反应堆完整度高于 25 时供电，并按升级等级给相邻电池或可充电机器补 1–4 点电。首版拟复用原版相邻关系和 `ProvidesPower` 判定余热可用性。余热处理是新增 MOD 机制，仍需验证相邻位置、失效和维修后恢复。成品机继续按真实组分判定。梦尘酒及双萃梦酒另要求梦尘含量 6%–12%，成品统一归为违禁品。
