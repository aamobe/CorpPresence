# 0.9.8 香水生产线更新

本次新增香水线，版本号继续使用0.9.8。

- 索拉纳金卡开放电话“香水工艺”。油花种子每滚动7天限购2颗，各机器限购1台，次日配送。
- 水培油花默认带芳香物质Ⅰ、不育Ⅹ。按营养果原版词条抑制返种，移除不育后可以返种；油花和烟草支持移入原版多年生。
- 花材打浆并用酒精在50℃以上温浸，产生含基底油的混合液。基底油提取器默认每次只扣10mL油成分，制成1份普通材料；不检查纯度，其他成分保留。
- 2袋普通血制成1份神经活性提取物，1袋蓝血制成1份费洛蒙提取物。
- 合成机以1份普通提取物加3份油材料制作神经活性香水；1份蓝血提取物加2份油材料制作费洛蒙香水。成品沿用原版物品及使用次数。
- 采血机所有实例共享每日次数。第一次无伤、第二次轻伤、第三次重伤；重伤不能抽血，每天最多3次，读档不重置次数。
- 性能增加加工批次；品质降低提油耗量、积累额外提取物或节省合成用油；效率沿用原版省电效果。采血次数和伤势不受性能、品质改变。
- 四种机器支持金属锭扩容：一级3块，二级另6块，每级增加2行。未加入电子元件耗电升级。
- 补齐原生物品、机器状态及水培植株精灵；支持多年生再次结果显示。
- 新材料与旧基底油液样瓶使用独立身份，旧瓶内容与机器储存顺序保留。
- 修复独立外壳物品读档时错误依赖旧ammo_box模板的问题。普通水继续沿用原版身份、纯度、估值和顾客判定。
