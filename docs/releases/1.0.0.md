# 1.0 稳定版

- 公司窗口、人物对话、生产线说明、物品描述、机器手册和配置展示文本统一使用1621个稳定本地化键。
- 接入游戏官方`ModHelper.GetLocalized()`及`Localization/*.csv`，提供完整英文、俄文、法文CSV，玩家修改译文无需重新编译DLL。
- 翻译文件由游戏加载器读取，模组不申请文件访问权限。
- 保留现有中英俄法文本、占位符、格式化和缺键回退；缺键、空译文和错误格式沿用现有文本。
- 菜单及品牌缓存适配官方CSV加载与游戏语言切换。
- 保留0.9.9香水线、索拉纳会员目录修复及现有玩法、价格规则、物品和存档标识。

翻译文件格式和使用方式见[玩家与译者说明](../localization/README.md)。
