# 1.0 稳定版

- 修复外部翻译包文件读取权限未声明，导致模组无法启用的问题。
- 将公司窗口、人物对话、生产线说明、物品描述、机器手册和配置展示文本统一迁移到1621个稳定本地化键。
- 支持外部JSON翻译包。玩家可编辑译文和新增语言，无需重新编译模组。
- 支持语言地区继承、部分翻译、缺键回退，以及错误文件和错误占位符的回退处理。
- 支持通过`language.json`选择本模组语言，菜单和品牌目录随翻译包重新加载刷新。
- 保留现有中英俄法文本及原有回退，提供俄语、法语参考包和完整翻译模板。
- 保留0.9.9香水线、索拉纳会员目录修复及现有玩法、价格规则、物品和存档标识。

翻译包使用方式见[玩家说明](../localization/README.md)。
