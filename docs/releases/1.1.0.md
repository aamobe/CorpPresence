# 1.1.0 · 仓库与分期工程

目标为既定 [Steam 创意工坊项目](https://steamcommunity.com/sharedfiles/filedetails/?id=3828913695)。当前正在准备发布，成功回执和回下载哈希确认后更新本记录。

新增专用工作仓、大型集装箱仓库、扩页模块与分类控制器；调整角色实际到店登记、立绘资源释放、作物生长与收获、订单提交和生产消费边界。具体行为见[更新日志](../../CHANGELOG.md)。

六期的修改、证据和保留检查集中在[分期核查表](../changes/runtime-performance/checkpoint.md)。独立只读审查覆盖相对 33744ab 的生产代码差异，未发现确认的 P1/P2 阻塞问题。审查不等同运行测试。

用户明确授权暂不进行游戏实测；游戏交互、完整剧情和实际内存/帧时间指标仍未验证。工坊改动说明按用户要求只记录功能与调整，不包含测试状态，也不声称已实测。

## 存档与回滚

旧档可继续；新增的仓库 ID、页签和分类设置仅由新版处理。使用新内容前应保留旧档备份。严重加载或存档问题出现时，保留现场并重新上传已保存的 1.0.1 发布文件；回退游戏进度使用对应旧版备份，不用旧版直接覆盖已使用新物品的存档。上一版文件哈希见 [1.0.1 发布记录](1.0.1-artifacts.json)。

## 后续可选游戏检查

- 各仓库扩容、改名、分类、满页拒收后存读档，检查页顺序和物品保持；控制器在箱中或待配送时不能重复购买。
- 各生产线正常/满输出生产，检查材料、电量和产物；烟草与油花检查不同健康档位下的成熟与收获。
- 角色到店、请离、下次来访；订阅到期与次日续订复查，检查剧情和还款状态。
- 反复开关面板、名片，切换语言、立绘档位和存档，检查字体、输入、纹理与对象数量趋势。
