## 不采纳的直接改法

- **S5 直接销毁 Goods/Cards Sprite**：当前为按有限身份复用的进程级资源，已交给原版物品 UI 使用。原版 GameItemElement 直接持有 Sprite；ModLoader 停用时只销毁本 Mod 自身 MonoBehaviour，并不清除原版物品 UI。Tex.ReleaseUi 因同样原因保留 art 纹理。立即 Destroy 会让活物品引用失效，因此不实施此建议，不能把它称为已复现泄漏。
- **按 GameResources.Generation 释放上述贴图**：该值是启用次数，不是实际图集内容代次。没有消费者解绑/重绑协议前，不能作为安全销毁依据。原版借用 Sprite 不归本 Mod 销毁，A7 的 fallback 也不混入自建资源缓存。
- **A2 每帧查表缓存/按 Version 缓存最终字符串**：同帧同 count 修改不会推进已有 Version。保留实时查表与官方 ModHelper 调用，仅缓存纯校验，避免显示旧语言或旧译文。
- **S5“价格事件改变 unitValue”**：原版 unitValue 是工厂基础值，事件价格在 GetCurrentValue 中另外叠加。本修复针对部分采样缓存和样品释放，不声称修复动态事件报价。
- **S1 用类型名文本次数作为强制依赖基线**：报告自己承认同名字段误计。可用于定位，不能直接当编译级依赖守卫；暂不加入会误报的门禁。

原版核对程序集 SHA256：`725CB999D019DFF1FF31BED353C7F9BB8D81A7605A15DE1F80F5A3A6CF7B1D05`。反编译输出仅留本机工作目录，不入仓库。美术资源若以后支持真实重载，须先解决原版消费者引用和资源归属，再增加释放。
