# 玩家外部翻译包

从CorpPresence 1.0.0起，翻译者可以只编辑UTF-8 JSON，为稳定键提供译文，无需重新编译DLL。已有旧版DLL不支持外部翻译包，需要先更新模组。

## 安装和选择语言

在实际加载的`CorpPresence.dll`旁新建`Translations`文件夹：

```text
CorpPresence.dll
Translations/
  es.json
  language.json
```

复制[西班牙语局部示例](examples/es.json)并编辑。每个文件的格式为：

```json
{
  "schemaVersion": 1,
  "locale": "es",
  "name": "Español",
  "translations": {
    "ui.menu.brandCatalog": "Catálogo de marcas",
    "ui.checkout.cash": "Efectivo {0}₵"
  }
}
```

`translations`中的键保持原样，只修改右侧字符串。`name`是给译者看的可选名称，不参与查询。可以只提供一部分键。

默认跟随游戏语言。例如游戏语言代码为`fr-CA`时，会依次查询`fr-ca`和`fr`包。语言代码忽略大小写，`pt_BR`与`pt-br`等价；支持多段代码，如`zh-Hant-TW`。

代码格式为2–8个英文字母的主语言，后续每段1–8个字母或数字，以`-`或`_`分隔；无需修改C#中的语言列表。

游戏菜单没有目标语言时，用[language.json示例](examples/language.json)选择本Mod的语言：

```json
{ "locale": "es" }
```

设置为`auto`或移除`language.json`即可跟随游戏。选择的代码必须有已加载的对应包或父语言包，否则记录提示并继续跟随游戏。这个选择仅作用于公司增强的文本，不改原版游戏语言、存档或配置保存值，也不向原版语言菜单注册新选项。

修改文件后重新启用Mod或重启游戏。文件不会每帧读取，不提供即时热加载按钮。加载会刷新语言及菜单缓存；文件始终由玩家维护，运行时不覆盖或自动生成它们。

## 回退和覆盖顺序

1. 当前完整语言代码的外部包，例如`pt-br`。
2. 逐级父语言外部包，例如`pt`。
3. 内置稳定键翻译（目前俄法）。
4. 旧表兼容回退，最后使用调用处英文；中文环境使用调用处中文。

外部包也可覆盖中文、英文、俄文和法文。没有外部包时保持现有文本和行为。中文包缺键仍返回原中文，不会因启用部分中文包而整页变成英文。

同语言可分成多个JSON文件；按文件名Ordinal顺序加载，较后的文件覆盖前面文件的同名非空条目。地区包优先级始终高于父语言，与文件名无关。空字符串、纯空白或缺键按缺译处理，不会抹掉先前有效条目。非字符串条目忽略；错误JSON、不支持的版本、非法语言代码和不可读文件只跳过该文件，不阻止其他包或内置文本使用。每个文件最大4 MiB，不递归扫描子文件夹。

## 占位符和样式

保留原文使用的全部编号，例如`{0}`、`{1}`。可以交换顺序或重复使用，也可保留或调整兼容的格式说明符，例如`{0:0.#}`；不能漏掉原编号或添加原文不存在的编号。

```json
"ui.checkout.voucherDetails": "A pagar {1}₵, cupón {0}₵"
```

实际显示花括号时写`{{`和`}}`。占位符语法或编号不符时回退到父语言/内置文本；格式说明符与实际参数类型不兼容时，格式化入口也继续回退，不将异常交给游戏UI。对齐宽度最多1024。

原文中的`\n`、富文本标签（如`<i>`、`<color=...>`）和参数各自含义应保留。数字格式仍按现有游戏运行文化格式化，选择外部语言不会改金额或玩法计算。

新增语言不附带字体或字形资源；实际字形、长句布局及点击区域需要在游戏里验收。本轮只完成静态/托管加载检查和编译，没有启动游戏。

## 获得全部1621个键

维护者可从源码导出完整模板：

```powershell
./tools/Export-TranslationTemplate.ps1 -Locale es -Name Español -OutputPath ./artifacts/es.template.json
```

该命令只生成JSON，不编译也不部署。默认将英文原文/模板作为值，方便对照翻译；**未完成条目应删除或清空**。保留英文值会作为显式译文覆盖该键，尤其制作俄法覆盖包时需留意。`-BlankValues`可导出全空值，`-Force`允许显式覆盖已有输出，默认保护已有文件。

英文参考来源是[迁移清单](../../tools/LocalizationChecks/Migration.json)，接口及稳定键规则见[维护说明](../maintenance/localization-keys.md)。翻译文件不包含代码，不需要改物品ID、存档键、配方成分或配置键。
