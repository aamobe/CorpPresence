# 0.9.9 默认难度调整

以 0.9.8fix3-preview 为基础，使用现有设置中的原版档位，减少额外的购买力、收购溢价和无限订货。全部公司剧情、新物品、机器和状态差分仍然启用。

| 设置 | 旧默认值 | 0.9.9 默认值 |
| --- | --- | --- |
| 公司人物携带信用点 `AgentBudget` | 10000 | 动态，800 + 随机 0～250 + 当前天数 |
| 服务强度 `ServiceStrength` | 标准 | 原版 |
| 人物收货价 `BuyPriceStrength` | 标准 | 原版 |
| 合作度：每多少信用点涨 1 点 `CoopCredits` | 100 | 400 |
| 订货每周限量 `OrderLimits` | 关闭 | 开启 |

服务与收购价格随原版档位发生以下变化。

| 内容 | 旧默认表现 | 0.9.9 默认表现 |
| --- | --- | --- |
| 索拉纳预约贵宾预算 | 3000～5000 | 800 + 随机 0～250 + 来访天数 |
| 实验室采购单收购倍率 | 普通货 2 倍，蓝血 3 倍 | 单上商品统一 1.5 倍 |
| 体力增强剂永久拾荒次数加成 | 每针 +1，不封顶 | 累计最多 +2 |
| 罗森日常批发折扣 | 七折 | 八折 |
| 米洛收海明威假烟 | 2 倍 | 1.5 倍 |
| 瑟琳日常收货 | 1.2 倍 | 1 倍 |
| 瑟琳收蓝血 | 3 倍 | 1.5 倍 |
| 公司交易、电话订货及相关付费服务的合作度 | 每 100 信用点 +1 | 每 400 信用点 +1 |
| 售出本公司产品、达夫雷售水的合作度 | 每 300 信用点 +1 | 每 1200 信用点 +1 |
| 一般电话订货限量 | 无通用限量 | 每样每周按基础价值分档，低于 50 为 20 份，50～199 为 10 份，200～299 为 5 份，300 及以上为 3 份 |

目录中单独规定限量的独家商品继续使用自身额度。补货周期仍为每周一次。

海明威标签戳单独固定售价为 400 信用点。米洛上门售卖和电话订货都不叠加违禁品溢价、市场事件、订购倍率或合作折扣。电话订货每期最多两个，新购标签戳可用八次。把自己的标签戳拖到另一个上可合并剩余次数，合计最多 24 次，超过上限时不能合并。

以下默认值保持不变。

- 恶意巨企模式关闭。
- 事件影响订货开启。
- 订购溢价 1.1 倍。普通公司随合作档位依次使用 1.1、1.05、1.0 倍。
- 每家公司每日合作度上限 10 点，剧情奖励与剧情保底继续不受这个上限限制。
- 人物日常来访、剧情章节间隔、服务冷却和机器生产配方保持原设定。

已有配置文件中的选项会被保留，更新版本不会强制改写。首次安装，或在模组设置中重置上表五项后，使用新默认值。只开新存档不会重置已有模组配置。

本次只调整默认设置。原先的标准服务强度、标准收货价和固定预算仍可手动选择。开启原版服务强度后，旧存档中超过两针的体力增强剂记录仍保留，实际拾荒加成按 +2 上限计算。
