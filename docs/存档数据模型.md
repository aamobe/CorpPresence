# 存档数据模型

## 0119 废料电池彩蛋（开发中）

新增根字段 `WasteBatteryGiftStatus`：0=未预约、1=待送达、2=已送达。旧档缺字段默认0，非法值拒绝读写；不重排现有字段与库存槽。独立物品ID `corp_presence_waste_battery`，贴图键 `corp_med_waste_battery`（另有 `_half`、`_empty`）。电量沿用原版 `power_source_item_energy` 与 `power_source_item_max_energy` 标签保存。物品创建不发礼物；仅实际放到柜台后登记已送达，满柜保留预约。重复拨号、读档不重复发放。

## 1231 芒果彩蛋（开发中）

公司根状态新增 `MangoGiftStatus` 整数，0=未预约，1=待送达，2=已送达；缺字段按 0，非法值拒绝读写，旧字段及槽位不变。新物品 `corp_presence_mango_warehouse`、`corp_presence_mango_backpack` 独立注册。芒果箱复用集装箱标签与原版页名保存方式；每件物品各自拥有标签，不共享库存。背包工厂只建立 12×10 原生库存，不绑定取空销毁，不生成礼品，避免读档补发；已送达标记和实际物品随正常存档一起保存。

## 专用工作仓（未发布）

大型集装箱仓库使用独立物品 ID `corp_presence_cargo_warehouse` 和扩页模块 ID `corp_presence_cargo_warehouse_module`。仓库标签 `corp_presence_cargo_extra_tabs` 保存额外页数（0–4），始终按原顺序在读档挂接库存前恢复，扩页只追加。博士的 `LimitedBought` 使用 `@cargo_warehouse@lifetime` 和 `@cargo_warehouse_module@lifetime`，在付款成功后记账，跨周期保留。

大型集装箱仓库外壳占实心 4×4 格。旧开发版的 3×3 仓库读档后，仅在原位置容得下 4×4 时扩占地。空间不足时保留原占格，移至空旷位置并保存重读即可重试。扩页数及仓内物品不参与迁移。

分类控制器 ID 为 `corp_presence_cargo_sort_controller`。仓库按页签顺序用 `corp_presence_cargo_filter_0` 至 `corp_presence_cargo_filter_4` 保存分类标签列表。空规则允许手动存入通用货物，仓体优先匹配有规则的页，再考虑空规则页。修改规则只影响新存入的物品。

分类控制器在店内已有实物或待配送订单时停售。实物检查涵盖已交付的配送箱和嵌套库存。旧测试版的 `@cargo_sort_controller@lifetime` 和周期购买计数保留，购买资格以实物和待配送订单为准。页签自定义名称沿用原版 `STORAGE_TAB_NAMES_STRING`。

- 新物品 ID 为 `corp_presence_production_work_bay`。无旧 ID、无迁移。原版 `machine_bay_ext` 仍是独立物品。
- 正式外壳贴图键为 `corp_med_production_work_bay`，占地为实心 4×4。较早的开发版可能保存了原版工作仓外壳。读档仅尝试更新这个公司物品的旧外壳与占格。位置放不下时保留旧外观和旧占格，玩家腾出空间后再读档即可重试，五页库存不参与迁移。
- 工厂在原版恢复子物品前按固定顺序建立五个 11×14 格库存：烟草、食品与水产、锻造、银血、香水。原版保存图节点关系及物品位置。后续版本不得重排这五个库存或复用其序号。
- 页签选中状态由原版 `CONTENT_TABS_STRING` 管理。缺少该标签时从第一页开始。物品整数标签 `CORP_WORK_BAY_LEVEL_INT` 记录 0–4 级，缺少时为 0，越界值按最近合法级别读。读档在放回子物品前恢复五页尺寸，各页均为 `(11 + 等级) × (14 + 等级)`。
- 私人订单商品键为 `@production_work_bay`。付款成功后在杰克逊博士的 `LimitedBought` 写入 `@production_work_bay@lifetime`，按存档限购，跨周不清理。旧开发版已有的待送订单或同商品购买计数也视为已购买。卸载前走既有公司物品清理，工作仓未腾空时保留。

玩法、接口与待测场景见[专用工作仓](specs/production-work-bay.md)。

## 卡尔特双胆反应槽

新增 corp_presence_cartel_reactor、corp_presence_blue_shell_resin、corp_presence_light_salt_core、corp_presence_sleep_moss_gel、corp_presence_light_salt_precipitate、corp_presence_zol_tablets、corp_presence_nicotine_tin、corp_presence_ice_shard_pouch。反应槽存档槽序为菌块、树脂、盐芯、蓝胆产出、白胆产出、精制进料、成品。CORP_CARTEL_BLUE_BATCH 与 CORP_CARTEL_WHITE_BATCH 分别记录 0 空闲、1 反应中、2 待出料，缺省为空闲。开批扣料，过夜推进，出料成功才清除该批。

### 卡尔特原版化学接入

原反应槽的七个槽位保持顺序，旧精制进料和成品槽改为只取出的回收槽。批次标签沿用。新增独立成分 corp_cartel_moss, corp_cartel_crystal 和 corp_cartel_salt；使用原版 CURRENT_PART_ 标签保存。三张原版精加工配方使用现有成品 ID，新增成分不修改旧配方。

冰棱反应产物使用独立成分 corp_cartel_ice_active，以原版 CURRENT_PART_ 标签保存。先前保存的三种原料成分可参加新反应。冰棱物品 ID 沿用原值。

### 矿化机

新增物品 ID corp_presence_cartel_mineralizer。原版机器库存保存三个槽，顺序为晶种、培养水、矿材出料。CORP_MINERALIZER_GROWTH 保存 0–3 点进度，缺省为 0，3 点表示成熟待取。晶种随首个有效周期扣除，成功收获后归零。光盐芯仍沿用独立物品和货源。
### 接粉盒

新增物品 ID corp_presence_powder_box，容量 500 点。CORP_MINERAL_POWDER_TAG 标识接粉容器。金属、硅质、稀有金属、导电料、渣料分别使用 CORP_MINERAL_PART_METAL、CORP_MINERAL_PART_SILICA、CORP_MINERAL_PART_RARE_METAL、CORP_MINERAL_PART_CONDUCTIVE、CORP_MINERAL_PART_RESIDUE 保存。缺省均为 0。粉层颜色、总量和填充档位根据成分推导。无新增库存槽。

### 矿粉破碎机

新增 ID corp_presence_mineral_crusher。库存槽按投料、接粉盒、电源、模组顺序保存，电源与模组是追加槽位。每晚自动处理 3 至 5 件原版垃圾或废金属。机器标签 `CORP_CRUSHER_PRESERVE_RESIDUE` 为真时关闭高质量破碎，缺省或为假时启用原有质量加成。矿粉仍由接粉盒保存。

### 矿粉筛分机

物品 ID corp_presence_powder_sieve。库存槽顺序为电池、模组、进料接粉盒、旧取粉槽。旧槽仅在有存量接粉盒时显示，取出后隐藏。六个内置仓通过机器标签保存，分类仓标签 CORP_SIEVE_BIN_0 至 CORP_SIEVE_BIN_4 对应 PowderBox 成分顺序，回收仓按成分保存于 CORP_SIEVE_RECOVERY_0 至 CORP_SIEVE_RECOVERY_4。缺字段为零。每个分类仓和整个回收仓各容纳 1500 点。

六个内置粉盒槽依次追加在原槽位之后。粉盒作为机器仓存的交互入口，旧档打开面板时补齐，已有仓存继续使用原标签。

### 综合烧结工作站

物品 ID `corp_presence_sintering_station`。库存依次为电源、粉盒一、粉盒二、粉盒三、出料。已选配方以稳定字符串 ID 存入 `CORP_SINTERING_RECIPE`，缺省为 `metal_ingot`。配方目录和夜间取粉计划在运行时生成。

出料库存扩为 6×4 格，沿用原出料槽的库存序号。旧档的单件成品继续加载到该库存。

模组库存追加在出料库存之后，界面显示在电源旁。标签 `CORP_SINTERING_CARRY` 保存不足一批的产能点数（0–99），缺省为 0。

已移除旧开发版的 `common_electronic` 烧结配方。存档里的旧配方键按未知配方回退到 `metal_ingot`，原库存槽和已有成品保留。

### 综合工艺台

新增 `corp_presence_crafting_station`、`corp_presence_silicon_plate`、`corp_presence_electronic_substrate`、`corp_presence_electronic_blueprint`。工艺台的原版库存依次为蓝图、材料一、材料二、材料三、出料。蓝图随槽保存，可重复使用。手动单批完成，无新增全局字段、进度标签或旧档迁移。
