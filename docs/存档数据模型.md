### 矿粉破碎机

新增 ID corp_presence_mineral_crusher。库存槽按投料、接粉盒、电源、模组顺序保存，电源与模组是追加槽位。每晚自动处理 3 至 5 件原版垃圾或废金属。机器标签 `CORP_CRUSHER_PRESERVE_RESIDUE` 为真时关闭高质量破碎，缺省或为假时启用原有质量加成。矿粉仍由接粉盒保存。破碎机投料堆的临时标签 `CORP_CRUSHER_FEED_ORDER` 保存入仓次序（首堆为 1）；整堆移出时清除。老档无序号的存量先按格位从上到下、从左到右加工。

破碎机末尾追加成品格（索引 4），合金坯回磨的独立粉包进此格。烧结站末尾追加固体投料位（索引 6），配方键 wear_alloy_blank 与 filter_blank。工艺台末尾追加第四材料位（索引 5），工业工艺沿用 CORP_CRAFT_MILL_RECIPE，选择键为产物后缀。新框架制成的总成带 CORP_FILTER_NEW_FRAME 布尔标记，按单件保存。

原破碎机在成品格后追加齿辊槽（索引 5），旧档该槽为空，阿岑给料机的轴与套顺序照旧。`CORP_CRUSHER_HARD_DUTY` 是玩家选择的硬料档，缺省为普通档。硬料档只处理旧炉衬，缺辊、磨穿、缺合格来料、没电或没有接粉空间时保持档位与物料。`CORP_CRUSHER_HARD_NIGHT` 记录成功当夜的日计数加一，用于去重，缺省为零。`CORP_CRUSHER_LAST` 继续保存原七字段，硬料末字段 `hard_lining` 标明固定来料及实得五成分。

### 综合烧结工作站

物品 ID `corp_presence_sintering_station`。库存依次为电源、粉盒一、粉盒二、粉盒三、出料。已选配方以稳定字符串 ID 存入 `CORP_SINTERING_RECIPE`，缺省为 `metal_ingot`。配方目录和夜间取粉计划在运行时生成。

灰盒烧结出料库存为 9×6 格，沿用原出料槽的库存序号。旧档原有 6×4 范围及其中的成品保留。

模组库存追加在出料库存之后，界面显示在电源旁。标签 `CORP_SINTERING_CARRY` 保存不足一批的产能点数（0–99），缺省为 0。

烧结站在固体料槽后追加工业线圈和致密铸模（索引 7、8），旧档两槽为空。`CORP_SINTERING_TRIM` 保存玩家是否允许近配，缺省为关。近配影响试配棒，其他配方和组织处理仍各按原来的方式取料。精确试配可行时照原配方实扣 100 点。近配只在无法按比例精确取料时使用，最少超取且至多 8 点，由合格致密铸模在各原粉盒保留最多 5 点超取量。两根铸棒的实配成分始终为目标 100 点，粉盒净扣减去成棒总质量是飞散量。`CORP_SINTERING_LAST` 沿用七字段，其中第六字段记录飞散的五成分，旧档为零。致密铸模物品 `corp_presence_dense_trial_die` 用普通成形件版本 1 写实际材料、检测样和致密工艺。工业线圈按图册权限和实物低损组织减少当前机器电耗 3 点，下限为 1，两种工艺与加装前使用同一配方 ID 和存档布局。

固定棒模追加稳定配方 ID `standard_alloy_rod`、`wear_alloy_rod`、`conductive_alloy_rod`，对应物品 ID 在配方 ID 前加 `corp_presence_`。每炉两根独立 1×2 物品。新棒在整批入出料区前写入实物标签 `CORP_ROD_MATERIAL`。首个字段为版本 `1`，其后按金属、硅质、稀有金属、导电、渣的顺序记录本棒各成分，以半粉点为单位，用 `|` 分隔。耐磨棒的 `1|45|0|5|0|0` 对应 22.5 金属和 2.5 稀有粉点。两根材料之和等于本次实际扣粉。

`RodMaterial.Read` 读取三个固定棒及试配棒物品 ID。旧固定棒缺标签时按首批固定配方读取，打开界面无需写回档案。标签未知版本或损坏时返回无档案，调用方不得用固定配方替代。数值从当前实料的成分比例折算到 100 点再按铸态算式向下取整。工序履历与组织随棒后加工接入。既有配方 ID、槽位及存档读法保持原顺序。

试配模式的配方和成品 ID 分别为 `trial_alloy_rod` 和 `corp_presence_trial_alloy_rod`。机器标签 `CORP_SINTERING_TRIAL_BLEND` 为五种成分整粉点数，用 `|` 分隔，顺序同接粉盒。缺省样方为 64／18／8／8／2。标签不合格时停止该配方，玩家可重新确认配比。成品用同一材料标签保存半粉点数，试配棒缺少材料标签时没有有效档案。沿用三个粉盒槽，每炉 100 粉点，按粉盒组成和原有比例取料规则配出指定成分，产出两根。若多组取量都符合配方，优先从靠前的槽取较多粉料。

组织处理沿用烧结站的固体料槽。机器标签 `CORP_SINTERING_ROD_JOB` 存一次待加工工艺，棒料标签 `CORP_ROD_PROCESS` 存实际完成的工艺，两处值为 `temper`、`densify`、`align` 或 `harden`。缺省分别是没有待加工和铸态。未知的值不可用于加工或验规格。首段每根只接受一道组织处理；在原件上写履历，材料档案和实物不移位，也不扣粉。缺电时保留待加工工艺，成功后取消排程。切换配方也可取消，取消后不挪动物品。

阿岑的整棒收购使用 `Workshop.Sales.Rods`，沿用现货收购凭单的实收、实付和完成日字段。旧档缺该字段时无凭单。整棒收购每日任选一份，有未结凭单先结清。报价使用稳定订单 ID `rod_batch_stock`、`rod_fatigue_stock`、`rod_hard_stock` 和 `rod_conductor_stock`，每单收一根。快照待结款时从凭单金额续付，无需再选实物。

综合工艺台在现有配方之后追加 `short_alloy_rod`、`rolled_alloy_strip`、`drawn_wire_blank`、`porous_sleeve_blank`。配方仍用 `CORP_CRAFT_MILL_RECIPE`。四种成品和 `alloy_offcut` 同用 `CORP_ROD_MATERIAL` 记录实物质量，另以 `CORP_STOCK_ASSAY` 记录原棒的成分检测样，格式同为版本 1 的五成分记录。前者按半点质量守恒，后者保留同一炉段的冶金读数，避免拆段后因小数取整改变组织门槛。继承本件能保留的 `CORP_ROD_PROCESS`。新坯件缺材料记录或检测样视为无档案。用物品 ID 区分完整棒、短段、连续带／线和边料，不改现有槽序。

## 子午线框架

锻台旧库存保持原顺序，说明书槽之后追加合金粉槽。工业锻造按钮直接加工，不改变已有刀型标签。每框架只从普通容器原版 water 成分减 100,000 µL，酒精和杂质原量保留。资格读取阿岑二访与罗森锻造支线或已有锻具的记录。

Workshop.Commission 缺省为空。Quantity 为本单件数（1–4），Ingots 与 Alloy 分别是已经收取的合格金属锭和耐磨合金粉数量，Paid 为实扣加工费（每件 35 元，包括券）。InFlight 表示一次库存或钱包回调的结果尚未核实；未核实的凭单冻结，已核实的部分只补差额。钱料齐后一次性清除凭单，更新子午线 LastOrderDay，在原 Companies["meridian"].Orders 添加 Kind 为 frame_commission 的订单。Items 每个 corp_presence_pump_frame 是一件待交框架。首次 Day 是办妥日加二；预约送货员保留该日，仅在当前会话标记当日已排队，重读后按未签收数量重排。送达玩家一侧柜台才逐件核销，满柜或部分送达后 Day 更新为下一次送货日。 罗森报废触点的订货标识和箱单 Kind 均为 @rosen_spent_contact；一对记两件。含该货的箱单沿用玩家侧柜台，旧清单按物品标识识别。其他子午线订单仍走原配送柜台。

## 水站轮换与返修壳

`Workshop.Rotations` 缺省是空列表，沿用版本 1 和现有首单。首单结清次日为窗口 0，每三天加一。`Window` 是签约窗口，`Serial=Window+2`，跳过的窗口不产生记录。同一 RunId 保留全部签过的实例。四种 `Kind` 按扩建、补给、返修、联合大修固定为 0–3；各车沿用首单的数量、实物号和实付凭单。每份返修保存两个壳位（0、1）。`Shells[].Issued/Returned/Delivered` 分别记录已领、已退、随末车交货，退回与交货互斥；`InFlight` 表示实物结果待核。末车结清另可领一件回收炉衬，`LiningClaimed` 为实领，`LiningInFlight` 为待核。

分级机在已有库存末尾追加索引 5 的重载筛垫槽，模式 3 选双份通量，配方标识 double.v1。工艺台末尾追加索引 6 的普通液体容器槽，工艺选项为 heavy_screen_pad、cleaned_filter_shell 和 dismantle_repair_filter，原 filter_unit 配方也接受本单净壳。带来源的壳和总成逐件存放：CORP_FILTER_RUN 为来源 RunId，CORP_FILTER_INSTANCE 为合同实例正整数，CORP_FILTER_SLOT 以 1、2 存储（程序索引 0、1）。全新框架总成沿用 CORP_FILTER_NEW_FRAME。

检修版分级机在筛垫之后追加工业线圈、精密支承两个库存槽（索引 6、7）。`corp_presence_classifier_support` 沿用成形件档案，`CORP_STOCK_TRUED=1` 记录去应力后的校直验收，须由实物的回火工艺和承力、脆裂、孔隙再判尺寸稳定。`CORP_CLASSIFIER_BATCH` 的原配方 ID 不变。实际开批时，`CORP_CLASSIFIER_ECO` 和 `CORP_CLASSIFIER_PRECISION` 选定该批砂料报价，缺省为假。近混粉资格只用于 fine.v1，低损只用于硅砂，晶磨与磨套寿命仍读原配方。两标记有一项为真时写 `CORP_CLASSIFIER_RIG_NIGHT` 为最后实际付电夜的日计数加一，防止重入再耗电；欠料恢复和成熟出料无需重新付电。交出整批才清两个规格标记。旧档没有新增标签时仍照原批次、原耗电和原取料门槛结算。

领退件与货款分别核销。物品标记销毁后若仍在原库存的子节点列表内，原版仍可把它写入存档，凭单须保持待核。柜台退款暂存中收到的本店保存请求延至实物交接结束。维护快照按实例号、车次和壳位给出累计实收、实付、已退和待核状态；历史已结清且没有待办的实例只计入总数。

## 运输井相位回收

`Workshop.PhaseSite` 默认缺省。该记录对应唯一的运输井停用泵组。请求勘察写 `SurveyDay`，次营业日班组布标完成。仅能在工程验收结清后创建。路线 `None/Crew/Parts/Whole` 分别为未签发、班组拆运、自有分装、相位整机。班组费用按实扣写 `CrewPaid`，扣费前置 `InFlight`；款齐才写 `DispatchDay`。自有路线保存站体原版编号 `StationId` 和实际电量 `PowerSpent`，确认货位、载荷和权属后登记，结算后更改设置不影响在途记录。班组和分装次日到货、整机两日到货，交接满柜可重试。实际落柜后记原版 `CargoId`，同一现场的其他路线不能重复出工。站体编号需在出发和回柜时都匹配。交接的整机沿用试水泵物品及槽序，标记 `CORP_PHASE_RECOVERED_RUN`，拆运件用旧工业线圈和旧炉衬实物。站体 `corp_presence_phase_recovery_station` 加一格电源，模式和校准档保存在 `CORP_PHASE_WHOLE` 与 `CORP_PHASE_LIFT`。

## 水站联合复工

折叠调度所产的新硅板记录 `CORP_FOLD_MADE_RUN`，与原有硅板用同一 ID，带来历的原件独立存放。综合工艺台以它制成 `water_service_kit`。相位站在原电源槽后追加复工泵与备件两槽。仅结合已完整回柜的原泵（来源 RunId、CargoId）和原相位站（StationId）可签发。

`Workshop.JointWaterWork` 缺省为空。签发保存 `SignedDay`、`KitId`。次日起登记 `ArrivalDay`，后续夜班在同一泵上付正常试水电和实液，通过后核销所装备件，写 `LoadDay`。再完成两夜实际供水，累计写 `ServiceNights` 与 `LastServiceDay`。每一阶段至少间隔一个营业日，按同一店铺和实物校验后提交。三笔款依次 90、135、235，`Paid` 保存实付总额，`InFlight` 表示付款结果待核，只有归入相应可支付边界的金额可续结。
