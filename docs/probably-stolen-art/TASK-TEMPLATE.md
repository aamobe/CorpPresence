# 素材任务记录模板

复制到具体素材的工作目录，填写后再制作。不确定项先查资源或代码，不通过猜测补全。

## 规格

```text
名称／资源键：
类别：库存物品 / 机器 / 动物 / UI图标 / 其他
交付阶段：概念 / 原生精灵 / 导入测试
原版参考资源及游戏版本哈希：
结构主参考：资源名＋继承的轮廓／视角／部件安排
材质参考：资源名＋外壳／玻璃／标签／指示色
风格对照：STYLE-REFERENCE.md中的类别及与原版并排检查结果
最终原生画布：W×H px
库存网格与形状：
主体包围盒／需保留留白：
锁定区域：
允许改装区域：
PPU / pivot / 纹理路径：
调色板：继承RGB列表＋新增材质色及用途
Alpha：参考实测 / 新作约束
状态：空载、工作等；每个差分的变化掩膜
缩放：输入尺寸 → 输出尺寸；倍率；采样原点；是否严格块复制
预计运行时纹理内存：
```

## 生成工具提示词骨架

以下提示只约束设计意图，不能替代像素验收。生成尺寸不等于最终母版尺寸。

```text
用途：Probably Stolen 的[类别]，与所附原版[资源名]一致。
参考1：原版结构和调色板；参考2（如有）：改装设计。
目标逻辑画布：[W×H]，最终必须在此像素网格上可读。
视角／体量／留白：[按原版填写]。
保留：[结构、材质、色值、轮廓特点]。
改动：[限定区域与功能]。
色彩：[具体RGB列表及允许新增颜色]；连续材质色块、明确像素边缘。
细节：[明确最终尺寸能保留的重点]。
状态差分：[只改变哪些内容]；笼体／机器公共结构完全对应。
透明：[外部透明；玻璃／主体如何表现]。
输出：无标签、无地面、无背景装饰；保持完整画布和统一原点。
```

若工具输出1024级图片，将其标记为设计参考。只有验证每个整数倍率块的RGBA一致并通过还原比较，才能作为可直接还原的放大母版。
