# 素材任务记录模板

> 现行精灵制作规则：检查本地 Aseprite，已安装时优先使用集成直接制作最终原生尺寸精灵；禁止生成预览图及缩放。详见 [美术规范](AGENTS.md)。本文已有图板、放大和缩放记录仅供历史参考或问题诊断，不作为新精灵制作步骤；验收直接读取原生 PNG 和像素数据。

复制到具体素材的工作目录，填写后再制作。不确定项先查资源或代码，不通过猜测补全。

## 生成工具提示词骨架

以下记录用于原生像素绘制，不能替代像素验收；画布、导出与最终母版尺寸必须一致。

```text
用途：Probably Stolen 的[类别]，与所附原版[资源名]一致。
参考1：原版结构和调色板；参考2（如有）：改装设计。
目标逻辑画布：[W×H]，最终必须在此像素网格上可读。
视角／体量／留白：[按原版填写]。
保留：[结构、材质、色值、轮廓特点]。
改动：[限定区域与功能]。
色彩：[具体RGB列表及允许新增颜色]；连续材质色块、明确像素边缘。
细节：[明确最终尺寸能保留的重点]。
状态差分：[只改变哪些内容]；笼体／机器公共结构完全对应。
透明：[外部透明；玻璃／主体如何表现]。
输出：无标签、无地面、无背景装饰；保持完整画布和统一原点。
```

工具输出尺寸不符时不得缩放交付，应回到目标原生尺寸重新制作。
