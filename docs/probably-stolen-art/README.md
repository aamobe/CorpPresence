# 深空当铺美术规范与参考目录

本目录整理自作者的`probably-stolen-art`资料，供公司MOD后续制作和维护。测量记录主要来自2026-11-05，输入文件哈希保留在证据中；它们是指定游戏/素材版本的分析，不是所有版本的官方美术参数。

## 按任务阅读

| 任务 | 必读材料 |
| --- | --- |
| 开始制作、修改或导入素材 | [总规范与验收](AGENTS.md) |
| 物品、机器、小型图标 | [原版抽样](REFERENCE.md)、[结构与材质参考](STYLE-REFERENCE.md) |
| 缩小、高清贴图、锯齿或杂色 | [缩放与防杂色](SCALING.md)，需要读完整流程 |

| 核对数据和重现分析 | [物品证据](evidence/README.md)、[人物证据](evidence/portraits/README.md)、[工具目录](tools/README.md) |

## 同步范围与边界

保留原目录的325张PNG参考/诊断图、元数据、统计和文档。PNG按原字节复制，没有缩放、重绘、限色或改Alpha；这些图位于文档目录，不进入模组运行时资源，也不替换[src/Assets](../../src/Assets)。

不收录本机`bin/obj`、工具DLL/EXE、调试符号、缓存，以及游戏类的整段IL转储。文档中的代码分析结论保留；需要再次核对IL时，使用本地合法安装的游戏与自己的工具依赖，输出只留本地。MOD自身立绘加载器的历史源码快照单独保留为证据，不当作当前运行代码。

原版游戏参考图用于本项目风格和显示分析；游戏素材与第三方组件权利不因收录而转移。分析用原图、概念图、诊断放大图和已验收原生精灵分别使用，不能混充交付物。

本次只整理并上传已有资料，没有在游戏里验证新素材，也没有执行分析脚本重生成图表。同步和检查范围见[工具说明](tools/README.md)。
