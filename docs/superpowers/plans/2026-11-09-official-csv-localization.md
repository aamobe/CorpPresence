# 官方CSV本地化接入

基线：GitHub main `857849ad143c1ae352a19cc2dc6d0c8879a0a108`，1.0零权限内置翻译版。

1. 为官方CSV查询、语言切换、加载时序、缺键/空值/格式错误回退添加定向检查，确认接入前失败。
2. 新增无文件访问的官方适配层，调用`ModHelper.GetLocalized`获取模板，在现有L/TextTranslations入口保留内置回退。菜单、数组和品牌缓存接入语言与加载状态；不改变玩法调用。
3. 用1621键审计与内置表导出`Localization/en.csv`、`ru.csv`、`fr.csv`，严格核对值、引号、换行、占位符。中文仍以调用处原文回退，允许官方中文CSV覆盖。
4. 在离线检查程序调用安装游戏的实际CSV值解析器，并按已核对的GetLocalized实现替代游戏API/语言边界，验证适配层行为；不启动游戏。
5. 编译、本地化回归、零权限扫描、独立审阅及文档检查通过后，更新工坊、回下载验证，再以预期旧提交保护更新GitHub main。

公开更新说明只列实际改动。保留内置表、中英回退和1621键；不恢复自行读写JSON或语言覆盖。CSV语言代码跟随游戏选中的语言，不自动新增游戏语言菜单项。
