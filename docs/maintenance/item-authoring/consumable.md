# 消耗品、药剂与可使用工具

遵循[共用契约](common-contract.md)。仅输出人工待办；不能由ordinary的MEDICAL分类生成使用效果。任何实际液体药剂或成分请求整单退出工具。

## 案例链与字段

[Goods](../../../src/CorpPresence/Items/Goods.cs)的CanUse→Use处理戒烟贴、面膜和蜡烛等；定义在[Goods.Definitions](../../../src/CorpPresence/Items/Goods.Definitions.cs)，状态归CorpState的药品状态。读取具体case后再扩展，不能复制全部Use分支。银血药品见[SilverBlood.Medicines](../../../src/CorpPresence/Production/SilverBlood.Medicines.cs)，涉及成分时只供独立开发参考。

需求字段：可用对象/所在库存、次数、效果单位、持续到哪一天、叠加是覆盖/最大值/累加、消耗一件还是扣次数、失败文案、离线/切档处理。日数边界必须说明包含当日与否；显示“3天”不能代替实际截止日定义。

| 转换 | 守卫/变更 | 消耗/输出 |
| --- | --- | --- |
| 不可用→可用 | 当前档、玩家条件、物品身份均有效 | 不改变状态 |
| 使用→生效 | 再次校验资格，再写所属存档效果 | 成功才消耗；可重复工具保留并扣次数 |
| 生效→到期 | 原有每日规则读取截止日 | 不在UI绘制时重复结算 |
| 重载/切档 | 恢复当前档状态、重绑显示 | 不续期、不把旧档效果带过来 |

效果持久字段归模组状态，原版物品销毁和库存归原版。新建赋默认次数；读档恢复现有次数；迁移保留玩家状态。获取沿公司目录，使用沿本类case，销售仍需独立确认允许与否，耗尽后清理引用。

反例：先销毁物品再发现玩家条件不满足；每次读档把截止日设为今天+3造成无限续期。

[最小需求输入](../../../tools/ItemAuthoring/examples/consumable.json)不生成实现。代码检查优先使用条件/次数边界、效果到期、重复调用和跨档；实机只需一次成功/一次拒绝及生效后重载。具体药物化学和原版使用对象不在自动支持范围。
