# 多状态与组合物品

遵循[共用契约](common-contract.md)。状态机必须人工设计；不能通过增加两张图就宣称完整支持。

案例链：[Goods.Use/RefreshBattery](../../../src/CorpPresence/Items/Goods.cs)与[Goods.Catalog](../../../src/CorpPresence/Items/Goods.Definitions.cs)处理candle/candle_lit和电池状态图；[ItemIdentity](../../../src/CorpPresence/Items/ItemIdentity.cs)保留蜡烛旧身份映射。设备模式是持久标签，同一实例切图不一定需要新物品ID。

字段：每状态名称/身份/精灵/占格、切换触发、守卫、消耗、库存内容保留、持续期、组装/拆解数量守恒、旧状态迁移。要明确状态属于实例还是当前存档效果；不能让图像缓存成为权威状态。

| 转换 | 守卫/归属 | 消耗/输出 |
| --- | --- | --- |
| 未点燃→燃烧 | 本物品可用、当前档状态可写 | 记录效果和实例状态一次 |
| 有电→半电→空电 | 原版能量为权威 | 只更新派生外观，不额外耗电 |
| 组合→拆解 | 全部输入/输出空间可满足 | 数量、改造和内部内容守恒 |
| 重载旧状态 | 原版恢复后限定迁移 | 不按新建状态重置，也不重放切换副作用 |

原版拥有电量和库存；模组拥有自有截止日/模式，显示从权威字段推导。获取沿现有目录，使用/加工沿状态转换，出售前明确当前状态价值，销毁后清理自有引用。

反例：读档按默认满电图同时补满电量；把组合拆解的所有输出创建成功当作已放置成功，丢失内容或复制物品。

[示例](../../../tools/ItemAuthoring/examples/multistate.json)。代码检查非法转换、重复回调、边界电量、旧状态迁移和拆解守恒；实际新物品最小实机为一条完整转换链及中间态重载。复杂状态图/组合规则不自动生成。
