# 植物基因与生长专题

证据范围与程序集指纹见[原版契约](native-contracts.md)。现有案例是[油花](../../../src/CorpPresence/Production/Perfume.Plants.cs)与[CropHealth](../../../src/CorpPresence/Production/CropHealth.cs)，只作人工开发参考。油花的花浆涉及液体/化学成分，整项需求必须退出物品工具，走[独立流程](liquid-systems.md)。普通无液体植物也不自动生成生长实现。

## 身份、资源与字段

种子 SeedId、PlantDefinition 注册键、收获物 FlowerId 和植株精灵不是同一个身份。登记每个稳定 ID、所属注册表、图集及原生尺寸；库存占格与精灵像素分别记录。PlantDefinition 的 42 是生长所需进度，4 是基础产量，Refruit(21) 是再结果进度，不能在未核对机器推进频率时直接写成天数。

| 字段 | 当前案例含义 | 归属与持久化 |
| --- | --- | --- |
| health | 0–100 健康百分比 | 原版营养/污染影响；模组读取 |
| REQUIRED_PROGRESS / PROGRESS_ITEM_TARGET_TAG | 种子目标进度 | CropHealth 定向同步 |
| MACHINE_PROGRESS_TARGET_TAG | 机器收获目标 | 机器完成判定读取 |
| GROWING_PROGRESS | 种子显示进度 | 原版写入后由限定补丁同步机器值 |
| CORP_OILFLOWER_GENETICS_V2_TAG | 一次迁移标记 | 模组持久 state；非每帧重设 |
| production_corp_flower_mash | 芳香物质基因 | PlantTraitRegistry；等级效果不等于普通物品数量 |

## 状态与公式

| 状态/触发 | 条件与变化 | 消耗和输出 |
| --- | --- | --- |
| 未种植 → 生长 | 原版 InitSeedItem、StartGrowing；定义先注册 | 默认基因只用于首次创建 |
| 生长 tick | 原版先处理资源和健康，再调植物/基因回调 | 水肥由原版消耗，模组不重复扣除 |
| 健康影响成熟 | ceil(baseWork × (200-health)/100)，health 限制在0–100 | 当前模组规则，不是原版通用公式 |
| 成熟 → 收获 | 机器进度完成，调用 onHarvest | 健康≤30产量×0.5，≤70×0.75，否则×1；向下取整且至少1 |
| 多年生下一轮 | 必须确有 perennial 基因；原版重置机器周期 | 不是默认给所有油花多年生 |
| 非多年生收获结束 | 原版结束机器进度并销毁种子 | 返回种子仍受原版不育机制约束 |
| 移除/失活 | 使用原版移除路径；死亡条件须按具体需求核验 | 不虚构通用植物死亡阶段 |

## 基因与玩家改造

油花默认 infertile 3、芳香物质、complex_genome、frail；未默认赋 perennial。芳香物质新添花浆以16000微升为基数，乘 ctx.Scale 和 potent/weak 的分级倍率，只作用于本次新增成分，不再次放大原有成分。精确等级范围、互斥与玩家编辑入口需针对新增基因核对；不能从这个生产基因推导全部基因行为。

RepairFlowerGenetics 只处理本物品且没有V2标记的实例：保留已修改的V1不育等级，不把玩家移除的不育重新塞回。未版本化旧默认和特定历史等级才定向迁移。迁移末尾标记V2；第二次调用不应改变状态。

## 独立开发需求表与失败反例

需求必须列：种子/植株/产物ID关系，基因ID/等级/默认/互斥/作用阶段/保存位置，水肥污染消费者，成熟与再生规则，产量与种子返回规则，满输出处理，玩家改造保留，语言与状态图。涉及成分时不得交给工具生成。

反例一：读档后调用 InitSeedItem 重刷默认基因，覆盖玩家插入或移除的基因。反例二：只改种子显示目标，机器仍按旧目标收获，或把 potent 再次乘到全部已有成分。

代码验证优先覆盖健康0/30/31/70/71/100、迁移幂等、保留玩家基因、回调仅执行一次、机器与显示进度一致。实际开发植物后，必要实机仅选完整生长收获、一个多年生/基因组合和保存重载；本工具开发不启动游戏。满输出、移除、具体基因继承仍须在实际需求中证实，参考不代表已验收。
