# 种子与植物

本类完整字段、状态表、原版/模组所有权、迁移差异、基因公式和两项失败反例见[植物基因与生长专题](plant-growth-and-genes.md)，并遵循[共用契约](common-contract.md)。工具只输出需求待办。

案例接入链：种子稳定身份→PlantRegistry定义→HydroponicHelper初始化→CropHealth定向生长调整→收获物工厂→PlantTrait收获钩子→保存恢复。现有油花带化学成分，因此只能作为人工参考；不能把油花默认基因/成分照搬为工具生成模板。

填写[无液体植物需求示例](../../../tools/ItemAuthoring/examples/plant.json)时，必须在人工设计中补足种子/植株/收获物ID表、每阶段图像与占格、基因作用阶段/等级/互斥/玩家可修改性、营养污染消费者、成熟目标和再生周期。普通水培环境规则应在独立设计审查中核对；一旦提出新增液体或成分操作，生成器整单拒绝。

最小代码验证为健康边界、进度同步、迁移幂等、保留玩家基因、收获只执行一次。实际物品实机为完整生长收获与保存重载，选择一个多年生或基因组合；不能把文档演练当成植物已实现。
