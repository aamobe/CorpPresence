# 物品工具验收与评估

2026-11-12。开发起点e1f4439，生产源码仍对应1.2.0发布代码；工具、测试和参考位于开发目录，不进入Mod DLL或工坊包。本记录区分源码检查、生成演练和实际游戏行为。

## 价值：规范化与减少重复登记

规范化是工具的核心价值之一：身份规则、稳定文案键、转义、素材命名、目录接入和检查步骤保持一致，便于审查、排错、维护和跨机器交接。复杂类别统一记录状态、单位、所有权、保存、失败处理和验证边界；液体必须独立开发，不能通过普通商品模板绕过。

工具减少重复输入，不替代需求设计。不能用生成成功证明物品可用，不能用一次计时证明所有开发都提速。首版自动路径限定普通静态商品、已审阅的toothpaste基底和pastel日用目录；其余类别按参考工作，扩展基底或公司仍需独立核验。

## 代码证据

工具检查覆盖输入、路径、身份/文案冲突、转义、缺图、幂等、用户修改保留、预览到应用的依赖快照、中途写失败恢复，以及回滚时保留并发新修改。Windows真实目录联接额外验证返回UNSAFE_PATH；创建链接仅发生在隔离测试目录。

独立全分支审查发现三项P2：CSV真实换行违反游戏单行协议、下划线camel化导致文本键共用、空下划线段触发索引异常。已分别增加回归检查：CSV按游戏协议编码/解码；文本键核对物品归属；Spec/schema共同拒绝空分段。审查者复核三项闭合。最终核对还将会员门槛限制为PastelCo实际三个等级，防止生成永远不可买的商品。

额外真实生成样品包含逗号、双引号、LF/CRLF，编译后使用已安装游戏的CSV值解析器验证en/ru/fr各1665项完全往返；Check成功。该副本包含两个临时商品，全部留在忽略目录，未进入生产源码或资源。

便携检查已纳入ItemAuthoringChecks；维护入口同样纳入。未为未修改的游戏业务重复跑所有实机场景。src、manifest、正式Localization以及IdentityBaseline相对开发起点无差异，证明本次不增加玩家内容、不重写发布身份基线。旧发布包和工坊版本不变。

本机详细记录保留在忽略的artifacts：item-authoring-comparison的计时与两路检查、item-authoring-escape-check.log、item-authoring-link-check.log、item-authoring-final-portable.log。它们不包含在GitHub交付或工坊包；公开证据只保留本页的方法、结果和边界。
