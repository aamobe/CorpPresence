# 其他生物与逃逸物品

遵循[共用契约](common-contract.md)。非鱼类不要强套FishSpecies；工具只输出独立设计待办。

参考链：[RatWheelGenerator](../../../src/CorpPresence/Production/RatWheelGenerator.cs)的设备/生物交互与[EscapeePlacement.TryPlace](../../../src/CorpPresence/Companies/EscapeePlacement.cs)的逃逸后放置。后者只证明主库存和后仓可保存，不能把前柜台放置视为保存成功，也不能由放置工具推断生物具有养殖能力。

字段：物种/物品身份、是否属于原版鱼类、活动周期、逃逸守卫、容器限制、饥饿/死亡是否适用、捕获条件、重试状态、实际保存的库存位置、掉落/奖励归属。没有现有完整案例的物种状态明确待设计，不凭动物常识补API。

| 转换 | 守卫/归属 | 消耗/输出 |
| --- | --- | --- |
| 容器→逃逸 | 本物品限定条件；仅一次处理 | 先取得合法目标，失败保持可恢复状态 |
| 寻位→已保存 | 主库存或后仓实际parentInventory匹配 | 不把尝试TryAcceptAll当成功 |
| 捕获/死亡 | 对应原版或独立规则 | 奖励与原对象消耗顺序需明确 |
| 重载/切档 | 恢复当前档状态 | 不重放旧档逃逸事件或额外发奖 |

原版库存/保存归原版；模组只拥有自有生物行为与位置约束。反例：逃逸物放到不保存的前柜台后标记已完成；所有动物按鱼类初始化导致错误水环境和阶段回调。

[示例](../../../tools/ItemAuthoring/examples/creature.json)。检查身份过滤、寻位失败不丢物、重复事件、跨档；必要实机为逃逸/捕获一次及保存重载。没有完整新物种实现，不能把此参考称作通用生物框架。
