# 养殖活体与物种

完整案例、字段单位、阶段变化、所有权与两项失败反例见[养殖阶段专题](aquaculture-stages.md)，共用接入见[共用契约](common-contract.md)。与死亡原料及食品不同，本类不得自动登记为普通静态商品。

入口链为FishSpecies注册→独立壳体→InitFishItem→原版TickTank→阶段/形状/繁殖/死亡→人工设计的后续加工。银血的血量和环境豁免只属于银血，不是通用鱼类模型。不同物种的繁殖条件、出缸存活、成长空间不足必须逐项核对；不能用“原版有TryBreed”证明新物种可繁殖。

[示例](../../../tools/ItemAuthoring/examples/aquaculture.json)仅组织年龄/阶段/饲喂/持久化待办。输入不描述新成分、配液或灌装；若需求涉及这些能力，整单退出工具。物种定义的所有原版字段取值仍须人工设计。

代码检查优先当前身份过滤、年龄只结算一次、错误阶段拒收、空间边界、死亡和读档不重置。实际新增生物最小实机为一次阶段变化及重载，按需求再选一次繁殖或死亡转原料；本次只读演练不冒充实测。
