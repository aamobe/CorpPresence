# 公司增强下一次大更新方向评估

日期：2026-11-13。现状依据为公司增强 1.3.2 开发基线和本机原版 100-Rev13。玩家覆盖和制作成本为设计判断，尚无玩家分布或试玩数据。

| 方向 | 玩家能玩到什么 | 可以复用什么 | 相对成本和主要风险 |
| --- | --- | --- | --- |
| 卡尔特线 | 一条有连续来访、交货和关系选择的短线。普通旧档可以在营业中收到邀请。 | 公司来访、电话预约、交货与对话分支。原版药贩开局的卡尔特问候、周结和退出可作剧情参考。 | 中。主要工作是角色、台词与分支验收。原版日常来访检查限定药贩开局且未退出，普通旧档入口需要由 Mod 自己安排。 |
| 垃圾工艺 | 回收材料可用于修复旧设备或交公司翻新订单，形成中前期反复经营的玩法。 | 废料电池已有垃圾消耗入口，原版已有反应堆修理与熔炉垃圾处理模块。 | 中。新增配方和机器会带来美术、材料定价及满槽、断电、读档检查。官方预告 12 月中旬推出 Junker 开局、专长和新物品，具体配方目前未知。 |
| 终局扩展 | 已建立产线的旧档可做公司合约，在多个现有产线之间分配时间和资源。 | 五条产线、公司订购和配送、工作仓，以及撒该和反抗军已有章节。 | 跨线合约中高，改原版结局高。不同档的产权、公司进度、阵营选择差异大。原版也已预告扩展会影响空间站和结局的主线。 |

## 建议

先做卡尔特线。第一版聚焦一位联系人、三次关键来访和一次有后续的选择。让玩家先接一单，再决定继续合作还是退出，两条路分别改变后续来访和货源。用独立 Mod 进度承接普通旧档，原版药贩开局和退出状态作为分支验收场景。

垃圾工艺等原版 Junker 实装后再定物料和设备；届时优先考虑公司修复订单与翻新旧设备。终局可先定义为买下店铺后出现的跨公司合约。首单只用两条现有产线，让两种交付方案消耗不同资源并给不同回报，再看老档玩家愿不愿意接第二单。

本轮若暂缓卡尔特，现有公司玩法仍能继续，损失主要是一次有辨识度的剧情更新机会。若发布目标是召回已经通完公司线的老玩家，把跨公司终局合约提到首位。若主要面向中前期经营玩家，等 Junker 实装后重新评估垃圾工艺的差异化空间。
