# 芒果物品精灵记录

使用内置生图工具分别直接生成透明背景的独立芒果精灵，未生成概念场景图。工具返回的大图不能视为原生精灵，已按最终网格处理并修整后导入。

- 芒果背包：[PNG](../../../../src/Assets/CorpPresence.art.jackson_private.mango_backpack.png)，32×32，对应 2×2 实心占格，15 种不透明 RGB。
- 芒果箱：[PNG](../../../../src/Assets/CorpPresence.art.jackson_private.mango_warehouse.png)，16×16，对应 1×1 实心占格，11 种不透明 RGB。
- 外形与配色主参考为用户提供的芒果；原版小鱼物品作为有机物像素团块参考。配色取自原版颜色库。
- 生图要求：独立物品、金黄果肉色外皮、红色侧面、绿叶、透明背景；大芒果带可辨识的开口接缝与扣件，小芒果保持完整果实轮廓。
- 导入：按主体包围盒等比例采样到目标网格，使用原版色板；再在 32 像素网格修整盖缝、扣件、果梗及孤立红点。不是把最近邻缩小结果直接作为最终稿。
- 已检查原生与放大预览，清理无用途碎点，保留果皮明暗块和结构像素。Alpha 仅 0/255；不使用半透明边缘。既有加载器采用 Point 过滤、不生成 mipmap、HdScale 1。
- 游戏内的最终显示大小、背景对比及拖拽反馈仍须用户验证。
