## 原料来源：水培眠苔

卡尔特联系人首次给一批可立即加工的眠苔菌块，以及一份用于原版水培槽的眠苔接种材料。玩家可以收获菌块供应双胆反应槽，并从收获中保留下一轮的接种材料。联系人提供应急补货，蓝壳树脂和光盐芯仍按章节开放订购。

### 眠苔试玩数值

| 项目 | 首轮设定 |
| --- | --- |
| 成熟门槛 | 18 点生长进度。按每轮推进 1 点计为 18 个有效生长轮，实际天数随原版水培的进度结算。 |
| 用水 | 每个有效生长轮消耗 20 mL，18 轮基准合计 360 mL。 |
| 化学污染 | 每轮目标吸收当前存量的 28.28%，至少尝试吸收 1 mL，保留相当于水成分体积 0.04% 的残留。 |
| 重金属 | 每轮目标吸收当前存量的 28.28%，至少尝试吸收 1 mL，保留相当于水成分体积 0.06% 的残留。 |
| 成熟收获 | 固定 3 块眠苔菌块，另返 1 份接种材料。污染量暂不影响收获。 |

原版 100-Rev13 水芦苇的基准是 18 点进度、每轮用水 20 mL、净化 IV。眠苔沿用净化 IV 的吸收目标 10% × 4^0.75 ≈ 28.28%，以及原版残留下限的整数计算：化学污染为 16 ÷ 4，重金属为 25 ÷ 4 向下取整，结果分别为 4 和 6 个万分点。3 块菌块是本方案的试玩值，可供双胆共开一批后留一块备用。

每轮正常耗水后，用供水容器的剩余成分结算。两个目标成分分别以 µL 计算：实际吸收量 = min(距残留下限可吸收的存量, max(1,000 µL, 四舍五入后的目标吸收量))。低于残留下限时本轮吸收 0。有效生长轮才执行，缺水或断电暂停，成熟待收时停止。吸收量直接从对应污染成分扣除。清水同样可以培养，其他成分按原版水培规则结算。

例如，耗水结算后容器还剩 1,000 mL 水、10 mL 化学污染、5 mL 重金属，本轮分别吸收约 2.828 mL 和 1.414 mL。若两种污染各仅剩 0.8 mL，本轮分别吸收 0.4 mL 和 0.2 mL，保留 0.4 mL 和 0.6 mL。

处理后的水可以取出供酒精制备站使用。制备站读取取用时的实际成分，仍在水里的杂质按取用比例和原量带入酒精混合液。化学模组继续只降低本站新增杂质。

## 主线：分料、反应、精制

1. **装料与分配。** 共用料口按独立 ID `corp_presence_sleep_moss_block` 接收眠苔菌块。菌块参照原版梦菇（`dream_cap`），分类为 `CHEMICAL_SUPPLIES`，无违禁品标记。蓝胆放蓝壳树脂，白胆放光盐芯。拨动分料闸后，两路分别预览可开批数和缺项。灰盒每胆同时只跑一批，可单启一路。
2. **封胆反应。** 确认后锁定该批投入。蓝胆生成眠苔胶，白胆生成光盐析晶。两个进度独立，灰盒暂定过一次夜间结算后完成。任一路出料位满时保留已完成批次，腾空后取出；另一路仍可结算。保存和读档恢复各胆的投入、进度和待出料状态。
3. **原版搅拌。** 取出眠苔胶或光盐析晶，放入原版化学搅拌机并用化学容器接料。冰棱另需把光盐芯的成分搅入同一容器。每件含 8 mL 对应虚构成分和 1 mL 物理杂质。搅拌按原版档位转移；精加工再按原版化学模组档位引入物理杂质。
4. **原版化学精加工。** 在原版精加工机选卡尔特配方，每次出一件。配方要求干料，原版负责转移与纯度分级。卡尔特配方按将抽取的混合物检查有效成分占比和成品格。达标后由原版按比例转移整份混合料，原有杂质一并带入。冰棱按反应生成的冰棱活性物占比套用原版纯度档。双胆反应槽只产中间品，旧精制槽保留用于取回先前放入的物品。

**冰棱反应。** 参考原版奥克莫西先在容器里生成专属活性物、再精加工的结构。三种虚构成分搅入同一容器后，放上原版加热板，达到游戏内 50°C 时触发。按三种成分中最少的量等量消耗，消耗总体积的 95% 变为冰棱活性物，其余变成物理杂质。过量原料和已有杂质保留。以上是游戏内试玩参数。

| 成品 | 每次抽取 | 投入最低纯度 |
| --- | ---: | --- |
| 唑眠片 | 5 mL | 眠苔胶成分占 60% |
| 尼古袋 | 5 mL | 光盐析晶成分占 60% |
| 冰棱 | 15 mL | 冰棱活性物占 80% |

## 副线：酒精制备站

**输入**是营养果、进水容器、接液容器和可选的原版化学模组。面板预览本批可用热量、取用水量、酒精与水的预计体积，以及「进水带入」「制备新增」两类杂质。

### 试玩数值

每批消耗 **240 kcal 营养果热量 + 100 mL 水成分**，产出 **25 mL 酒精 + 100 mL 水 + 随进水带入的杂质 + 本机新增杂质**。每次操作结算一批。240 kcal 沿用达夫雷果糊的每份热量基准，水量和酒精产量是本站的游戏平衡值。水量按水成分计，进水混合液的实际抽取体积还包含随水带走的其他成分。

模组曲线参考本机原版 100-Rev13 的 MachineChemFinisher.GetLoss（0 至 4 个模组对应 12、6、3、1、0）。本站沿用这组档位，以每批 **125 mL 酒精与水的基础出料**为计算基数，附加工艺杂质。进水杂质不进入该基数。

| 原版化学模组数 | 新增量占基础出料 | 每批新增物理杂质 | 干净进水的总出料 |
| ---: | ---: | ---: | ---: |
| 0 | 12% | 15 mL | 140 mL |
| 1 | 6% | 7.5 mL | 132.5 mL |
| 2 | 3% | 3.75 mL | 128.75 mL |
| 3 | 1% | 1.25 mL | 126.25 mL |
| 4 | 0% | 0 mL | 125 mL |

### 批次结算

1. **校验热量与进水。** 营养果沿用现有热量读值，超过本批消耗的热量留在机器供下一批使用。热量低于 240 kcal 或水成分少于 100 mL 时保留投入。
2. **按取用比例转移成分。** 假设进水有 200 mL 水和 6 mL 杂质，本批取走 100 mL 水和 3 mL 杂质，输入容器留 100 mL 水和 3 mL 杂质。按原成分记录并转移，液体内部以 µL 记账。
3. **附加本站新增量。** 同一成分的带入量与新增量入瓶时相加。用上例的进水，无模组时总杂质为 18 mL，满档时仍有 3 mL，酒精均为 25 mL。
4. **整批提交。** 先校验接液容器能接收整批出料，再扣热量和进水。上例在无模组时需 143 mL 空间，满档需 128 mL。满槽、容器不兼容或投入不足时保留原料。

## 首轮试玩

- 只做蓝胆和唑眠片，跑通领料、开胆、过夜、精制、交货。
- 开两胆并堵住一侧出料，确认另一侧仍结算。保存重进，腾空后确认没有丢料或重复产出。
- 开放尼古袋和冰棱，检查订单是否让玩家改变两胆的备料分配。
- 用干净水和有杂质的水，分别在无模组与满档模组下制备。检查高档模组将新增杂质降为 0，带入杂质的绝对量仍一致。另测低热量、进水不足和接液满槽。
