# 卡尔特线与成瘾品产线提案

状态：讨论稿。名称、物料数量和门槛均为暂定设计。

## 原版接点

本机 100-Rev13 的梦尘与芬太片登记在 ChemFinisherRecipe，由 MachineChemFinisher 和 ChemFinisherUIManager 承接加工与界面。StoreClientListCartel 的原版周结识别梦尘，原版定期卡尔特来访受药贩开局与退出状态限制。本提案新增联系人、交货规则与独立机器，通过公司增强的来访机制向普通旧档开放。原版药贩开局可用不同开场对白进入同一条 Mod 产线。已退出原版卡尔特的存档建议只开放匿名现货交易，避开重新入会。

## 工艺

**主线：3 种原料 → 双胆反应槽转化 → 2 种反应中间品 → 原版化学精加工机完成 3 种成品。副线：营养果热量和进水 → 酒精制备站 → 含水与杂质的酒精混合液。**

### 两台卡尔特作坊设备

**美术方向：黑帮科技。** 卡尔特把成熟的工业和实验室模块拆来重组。核心组件有清楚的功能和完整的工业结构，粗粝感来自外露管线、异厂转接件、补焊支架和手写检修标记。手拨闸和手泵是现场操作件，设备的技术水平由核心模块体现。

| 设备 | 用途与玩家操作 | 作坊外观 |
| --- | --- | --- |
| **酒精制备站** | 投入营养果与水，以营养果的可用热量和实际取用的水量结算，向接液容器产出酒精、水与杂质的混合液。原版化学模组只降低制备新增的杂质，最低为 0；进水带入的杂质保留。 | 沿用现有罐体、工业模块与下方接液位。左侧改作进料，右侧为制备模块；界面增加原版化学模组槽。 |
| **双胆反应槽** | **三种成品必经的化学转化工位。** 蓝胆把虚构原料转化成眠苔胶，白胆把虚构原料转化成光盐析晶。两路共用菌块，玩家先分料，再启动任一路或两路。每路有自己的反应进度和出料位。一路满槽时，另一条可以独立结算。 | 两只带原厂法兰和读数窗的精密反应胆固定在补焊过的子午线铸铁架上。外露分流管接手拨分料闸，蓝白油漆标出两路，机械表针指示「可取料」。 |

玩家开工前可调整两路的投料比例，开工后该批锁定。已完成的中间品可单独取出囤放，再转入化学精加工机。唑眠片走蓝胆，尼古袋走白胆，冰棱要两路产物。普通订单可以先做一路，高阶订单得提前为两路都留料。灰盒用游戏内批次和进度表现反应。精加工机暂定接入三张独立配方，具体接入见制作流程。

酒精制备站暂定复用原版酒精成分与容器。它是独立副线；接入前验证成分、体积与索拉纳花材处理兼容性。详细结算见[制作流程](production-flow.md)。

## 卡尔特章节

1. **试单**。联系人带试料，解锁双胆反应槽和唑眠片订单；联系人同时提供独立的酒精制备试单。先做出一批并完成实际交货。
2. **指定订单**。解锁光盐析晶和尼古袋。订单提前说明数量、交付日和回款，玩家可自行决定是否接单。
3. **合作选择**。解锁冰棱。继续合作可预约批量原料与重复订单；保持距离可做零星现货单。两条路都保留已拥有的机器和已购材料。

首版经济差异放在供货节奏、订单量和占用产能。成品的使用效果、成瘾数值和原版阵营惩罚列为后续讨论项，首轮以经营循环验证三种货各自是否有用途。

## 实现顺序与验收

1. 灰盒先做唑眠片，从领料、分料、反应出料、转入精加工机到交货全链跑一遍。
2. 加光盐析晶、尼古袋和冰棱，用有限原料测试玩家是否愿意在三种货之间分配产能。
3. 接联系人与分支，核对普通旧档、原版药贩开局、已退出卡尔特三种入口。再定售价、来访频率和美术。
4. 正式接入前锁定物品 ID、机器槽位顺序、进度字段和旧档默认值。验证满槽与原料不足时不扣料、读档保留库存、两路反应独立结算、进行中批次存读档保持进度、三个成品均需先反应再精加工、营养果热量与进水按实际用量扣除、满模组只消除制备杂质、交货失败可重试、原版梦尘和芬太片仍能照常制作与交货。
