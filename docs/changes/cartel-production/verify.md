# 眠苔游戏内验证

- 用开发者物品生成器按 ID 查 corp_presence_sleep_moss_seed。取一份接种包，装入原版水培槽，供水供电。观察三阶段覆盖图，默认进度跨过 6 点和 12 点时换图。
- 记录供水成分，过一轮核对用水 20 mL 和化学污染、重金属的吸收。用含第三种污染成分的水对照原版普通耗水，再检查停电、缺水时没有额外吸收。
- 进度到 18 时等原版自动结算，检查 3 块菌块及 1 份接种包。分别测试有空位和出料已满。
- 生长途中保存并重进，检查阶段恢复。旁边种原版水芦苇，核对原版图层和产出。

## 双胆反应槽实测

- 用开发者物品生成器取 corp_presence_cartel_reactor、corp_presence_sleep_moss_block、corp_presence_blue_shell_resin 和 corp_presence_light_salt_core。用无关物品尝试各进料槽，确认槽位只收对应独立 ID。
- 蓝白各开一批并过夜。阻塞一侧出料后，检查另一侧正常结算；存读档后腾空并按「尝试取料」，确认产物只领一次。
- 在原版搅拌机将中间品打入化学容器，再在原版精加工机分别选三种卡尔特配方。每批出一件，干料带杂质但达标时能开工，低于纯度门槛、含水、冰棱未生成足量活性物或出料格满时拒绝。对照无模组与满模组的出品纯度，并确认原版梦尘和芬太片仍可正常精加工。

- 将三种冰棱原料搅到同一容器。加热前应无法精加工；加热后查看冰棱活性物和新增物理杂质，再验证 80% 门槛与原版纯度等级。
