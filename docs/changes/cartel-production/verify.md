# 眠苔游戏内验证

- 用开发者物品生成器按 ID 查 corp_presence_sleep_moss_seed。取一份接种包，装入原版水培槽，供水供电。观察三阶段覆盖图，默认进度跨过 6 点和 12 点时换图。
- 记录供水成分，过一轮核对用水 20 mL 和化学污染、重金属的吸收。用含第三种污染成分的水对照原版普通耗水，再检查停电、缺水时没有额外吸收。
- 进度到 18 时等原版自动结算，检查 3 块菌块及 1 份接种包。分别测试有空位和出料已满。
- 生长途中保存并重进，检查阶段恢复。旁边种原版水芦苇，核对原版图层和产出。

## 普通存档的黑羽静灰盒

1. 从声望 10 的卡尔特普通档等首访。自己一侧柜台留位收接种包，在记事簿联系黑羽静领料。分别在柜台塞满、只领到部分、已领尽时存读；核对累计只实领一台反应槽、两块菌、两份树脂。已过首访的旧档从记事簿开始。
2. 同一反应槽依次试 7 电、8 电但蓝胆满仓、8 电且有空位。前两次保留料电。第三次出一块胶后直接从出料格交首单；核对实收 55 元，跨日重读仍可订 300 元酒精站，再次点击首单不多收胶、不多付钱。
3. 玩到阿岑二访成交，等黑羽静预约并实际送图。送图前核对磨套的锁因；送图后从两个联系人分别订分级机与磨套，并验收次日送货。矿化机喂两独立合格粉盒、水与电池，第一夜后存读、拔图；第二夜故意只留一个芯位。腾出第二个位置后，确认整批两枚只交一次，水电累计为 40 mL、12 电。
4. 拿其中一枚芯和余下一块菌喂白胆，蓝胆留空树脂，过夜用 8 电得一份析晶。在分级机选晶磨，第一夜后存读，确认不能拆走磨套或换档。第二夜满仓时保留已熟批次，腾位后收两包晶粉。用一包翻新原磨套，核对接下来的四批依次为一、一、一、两夜。
5. 核对 9×6 进出料格的拖放、原版电池槽和提示文字在游戏分辨率下可读。留存读档前后柜台、钱包、液体量和批次提示的截图，并记录所测构建。

## 双胆反应槽实测

- 用开发者物品生成器取 corp_presence_cartel_reactor、corp_presence_sleep_moss_block、corp_presence_blue_shell_resin 和 corp_presence_light_salt_core。用无关物品尝试各进料槽，确认槽位只收对应独立 ID。
- 蓝白分别装入辅料，共用槽放两块菌块。确认三个进料格和两个出料格为 9×6。先取下电池过夜，确认无产出、无扣料。再装入充足电量的电池过夜，应各出一件并共扣 16 电。电量只够一批时蓝胆优先。填满一侧出料格后过夜，确认该路不扣料和电、另一路正常结算。读旧档时核对原料、成品和已开批状态，腾空后用「取回旧批次」检查旧批只出料一次。
- 在原版搅拌机将中间品打入化学容器，再在原版精加工机分别选三种卡尔特配方。每批出一件，干料带杂质但达标时能开工，低于纯度门槛、含水、冰棱未生成足量活性物或出料格满时拒绝。对照无模组与满模组的出品纯度，并确认原版梦尘和芬太片仍可正常精加工。

- 将三种冰棱原料搅到同一容器。加热前应无法精加工；加热后查看冰棱活性物和新增物理杂质，再验证 80% 门槛与原版纯度等级。
- 打开新反应槽，应看不到旧批次按钮。放菌块，再只放蓝壳树脂，核对白胆提示缺光盐芯。放满一侧出料格后应提示清出对应出料格。取走成品时应立即刷新。旧档中仅有已成熟待取的批次时显示取回按钮。

## 酒精制备站实测

- 用 F3 卡尔特测试箱或生成器取 corp_presence_alcohol_preparation_station。确认营养果、进水和接液容器各有 9×6 格，另有电池槽。电池缺失或电量不足时过夜，确认热量、原料和液体均保留；有效夜晚应扣 8 电。放入营养果、进水和接液容器，确认面板提示今晚可制备后过夜。再用多组果子和多个容器验证，第一只接液容器满了应使用另一个有空间的容器。无模组且进水干净时，每批扣 240 kcal 和 100 mL 水，接液增加 30 mL 酒精、100 mL 水和 15.6 mL 物理杂质。
- 用 200 mL 水和 6 mL 杂质的进水测一批，取走 100 mL 水和 3 mL 原有杂质。四个化学模组只消除本站新增量，仍应带入这 3 mL。
- 用不足 100 mL 水或剩余空间不足的容器过夜。确认失败不扣料或电。用大果产生剩余热量，保存重进后核对热量，再继续制备。
- 先装上电池、营养果。依次测试没有进水容器、两只容器各含 50 mL 水、有水但没有接液容器，以及两只接液容器各余 100 mL。应分别提示放进水容器、单只须含 100 mL 水、放接液容器、单只所需空量；无模组、纯水时为 145.6 mL。换成足够大的容器，应当场显示今晚可制备。
- 对照同样成分和装量的原版普通水容器，检查鉴定、倒装、分类、原版报价与顾客收货。将产液用于索拉纳花材提取，确认能读到酒精成分。

- 两台机器分别装入有余量的电池，存档重进后检查电池所在槽位与当前电量，再过夜核对耗电。双胆旧档有待取物品时应显示对应回收区，取空后收起；再开面板确认显示正确。

- 完成黑羽静首访后，分别验证声望 40 但未买矿化机时不送图，以及低于 40 但已买进阶套装时预约送图。每日限一名访客时，旧档未解锁的送图预约应让出当天名额给阿岑。满柜无法送图时，黑羽静应正常离场、保留预约；腾出柜台后只交一张可重复使用的蓝图，检查说明中的完整配方。
