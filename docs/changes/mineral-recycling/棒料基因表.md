# 棒料基因表

工业线设计稿。表内门槛和收益用于首轮试玩。基础算式见[棒材特性与工艺](棒材特性与工艺.md)，螺丝刀开盖及换件流程见[可换件机器与全线改装](可换件机器与全线改装.md)。

两种基因能否共存、哪道工艺会挤掉原有特性，以及数值达标时何时显示「高硬度」等独立标签，见[完整配伍矩阵、模组与装机路线](棒料配伍与装机路线.md)。

## 配料索引

一炉 100 点。五种成分依次为**金属／硅质／稀有金属／导电／渣**。读数依次为**承力／耐磨／导电／耐蚀／脆裂／孔隙**。前四项越高越能承担对应工作，后两项按用途选窗口。样方供起步和复产，组织判定读取实际材料与工序。

| 炉料 | 五成分 | 铸态六项读数 | 适合从哪里起步 |
|---|---|---|---|
| A 耐磨料 | 64／18／8／8／2 | 57／52／32／38／8／6 | 同炉分做轴、含油轴套或压头 |
| B 导电料 | 64／7／7／20／2 | 56／28／67／24／0／6 | 省电线圈、大电流绕组或细丝 |
| C 耐蚀料 | 68／8／15／8／1 | 66／46／39／51／0／3 | 泵壳、耐蚀包套、精密夹具 |
| D 常备结构料 | 80／10／3／5／2 | 66／26／18／15／0／6 | 承力芯、抗冲击件、短销 |
| E 高硅工具料 | 60／23／11／5／1 | 56／68／26／54／13／3 | 可换齿面、拉丝模的耐磨接触面 |
| F 省稀有耐磨料 | 65／20／5／8／2 | 56／50／29／31／10／6 | 普通给料轴、轴套；每炉比 A 少用 3 点稀有粉 |

## 十二项基因

每行描述一种可检验的材料组织。数值取该工序完成后的结果。工艺栏中「回火」统一为承力减 4、脆裂减 5；「致密」为孔隙减 4；下限均为零。「定向」要求原始导电 ≥60，沿绕制方向导电加 8、脆裂加 3。「表面硬化」使外层耐磨加 6、脆裂加 3。浸油、拉丝、磨面、校直等精整工序在本表中只记录实际工艺或消耗。初期每段只选一道组织处理；高级芯、套可分开处理再装配。

| 基因 | 显化条件与样方 | 做成什么，装机后改变什么 | 取舍 |
|---|---|---|---|
| 承载骨架 | 承力 ≥64、脆裂 ≤4；D 铸态 | 机架、绞盘芯轴，提高额定载重 | D 的耐磨仅 26，裸轴接触面需另配套 |
| 耐疲劳 | 回火后耐磨 ≥50、脆裂 ≤5；A 或 F | 给料轴配含油轴套，开放同夜连续进给 | F 能接普通班，频繁启停单要求耐磨 ≥52、脆裂 ≤3，须用 A 或同规格替料 |
| 抗冲击 | 回火后承力 ≥60、脆裂 ≤2；D | 起停联轴器，承受更高的瞬时冲击 | 回火使 D 的承力从 66 降到 62，做重载静梁时原棒更合适 |
| 储油孔隙 | 耐磨 ≥40、孔隙 5–9，保孔精整；A 或 F | 轴套浸油后能维持连续班；干套可接普通班 | 需要补油。A 一旦致密到孔隙 2，便失去储油窗口 |
| 耐压密封 | 承力 ≥50、耐蚀 ≥35、孔隙 ≤3，精磨密封面；A 先致密，或 C 直接磨面 | 泵壳通过压力试验；压头减少配方列明的漏料 | A 多一道致密工序，C 每炉占用更多稀有粉 |
| 低损导电 | 导电 ≥60、孔隙 ≤3且完成致密组织处理；B 致密 | 低损线圈降低启动电，余电也可开小批 | 电机的重载峰值另由绕组规格决定 |
| 定向导电 | 定向后沿轴导电 ≥75、脆裂 ≤4；B 定向到 75／3 | 沿标记方向绕制可承担重吊峰值负载 | 弯折处更脆，方向优势只作用于沿向部位 |
| 延展细丝 | 导电 ≥60、脆裂 ≤2、耐磨 ≤35，经拉丝模精整；B 铸态拉丝 | 绕制细线圈，同一个小机身能装下所需匝数 | 占用拉丝模；B 定向后脆裂 3，错过细拉窗口 |
| 耐蚀表层 | 接液外层耐蚀 ≥45、孔隙 ≤3，表面精整；C | 湿区触点、泵套在浑水中维持更久 | 翻磨会消耗实际层厚，磨穿后露出芯材 |
| 硬质齿面 | 硬化后外层耐磨 ≥70；E 达 74 | 破碎齿或拉丝模接触面可多工作若干批再换面 | 外层脆裂达 16，冲击由独立的韧芯承担 |
| 尺寸稳定 | 承力 ≥60、孔隙 ≤3、脆裂 ≤3，经去应力和校直；C | 定心夹具通过薄壁精整，开启薄套加工、降低单件用料 | 需占一个精整工位；厚套长单更看重翻磨余量 |
| 均匀剪切 | 承力 60–68、耐磨 ≤35、脆裂 ≤3，按样销做剪切标定；D 短料 | 切成保险销，换销颈可选 5／7／10 格的脱开刻度 | 遇阻脱开要换实物销；脱开刻度由材料和销颈共同确定 |

## 继承、组合与品系记录

- **整棒继承。** 切下的实料保留五成分、组织与工艺。脆裂、孔隙随材料一起走。浸油量、销颈和套层厚度属于实物状态，另行记录。分料按质量守恒，部件按同一 100 点尺度读取组成比例。
- **跨炉留种。** 首轮仅「耐疲劳」「低损导电」可用 5 点晶种引导 95 点新粉，合格可省一道组织处理机夜。其余十项可保存配方卡复产。后代从新炉实际五成分验算一次，代数只记谱系。
- **同炉可以多用。** 样方达到多项门槛时记录全部符合项，由零件位置选用。D 铸态做梁，另一段回火做联轴器，剩余短料标定成销。每个机器参数只结算一次。
- **芯与外层分别继承。** D 回火芯＋E 硬化齿面做可换齿辊；B 导电芯＋C 耐蚀套做湿区触点。每层记其实际质量和位置。碰到冲击验芯，长期磨损验齿面，接液验外套；换掉外套后只重验受影响的项目。

用螺丝刀开盖后，动力槽显示线圈影响的启动电和峰值，工艺槽显示压头能省的实际损耗，传动槽显示轴及轴套允许的班次。零件图直接标明尚缺的搭配，例如「已有耐疲劳轴，配含油轴套可连跑第二筐」。配方预览、试机、装机和子午线规格单共享同一份组织判定及部位规格。
