# 接粉盒精灵

对应[矿物回收线提案](proposal.md)。接粉盒占 3×3 格，盒体和五张粉层共用 48×48 原生画布及左上原点。空盒只画固定盒体，有粉时按矿粉总量叠一张粉层。只给粉层乘色，盒沿、盖扣及高光保持原色。[可编辑母版](../../../src/CorpPresence/assets/mineral-recycling/Draw-PowderBox.ps1)直接在原生网格上绘制。

盒形延续原版弹药盒的平盖与立壁。分层和塑料材质参考本机 100-Rev13 水容器的 `xl`、`pitcher` 和 `WaterHelper` 同原点叠图方式。接入时核对 Point 过滤、Sprite pivot、PPU 和 Canvas 显示。

## 原生验收

六张图均为 48×48，重新生成的 SHA-256 逐张一致。盒体的九个原版 MOD 格取样点全部有效。盒体 Alpha 0/112/255 分别为 680/832/792 像素。五档粉层只含中性灰，不透明像素全部落在 Alpha 112 的窗口内，和不透明盒沿、盖扣及高光零重叠。绘制未用缩放。
