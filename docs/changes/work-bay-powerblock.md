# 专用工作仓接收能源阵列

五个产线标签页均允许原版能源阵列（powerblock）。原版阵列只有机器分类，没有 power_source_item 标签，因此之前被工作仓分类规则拒绝。

只扩大专用工作仓的明确物品名单；五页共用同一入口。已有物品、库存顺序、升级标签及所有权限制不变。阵列对同一库存中相邻电池和可充电机器的充电仍由原版回调负责，不新增跨页供电。拖到仓体沿用通用物品默认归入第一页的行为；选择其他页后直接放入该页。

验证：新增编译产物回归检查，修改前确认第一页拒绝；修改后检查五页放行、非法页码/空物品拒绝、无关物品拒绝和金属锭原有分类。未部署，游戏内未实测。

待游戏验证：在每页分别放入已拥有的能源阵列；相邻摆放可充电电池并过夜；保存重进，确认阵列位置保留并可继续放入或取出。
