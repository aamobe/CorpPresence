源码核对 Malice.OnDayStart：处理模式开关后，先运行反抗军每日逻辑，再逐公司处理到期自动续订和提醒，最后调用 Envoy.OnDayStart 与 RebelStory.OnDayStart。订阅有效条件为 SubUntil > Day；到期自动续订在 SubUntil == Day 时尝试。TryAutoRenew 在现金扣除代金券抵扣后的费用仍足以交租时才调用 Subscribe。此处为源码证据，未证明回调异常、跨档和扣款失败下的完整事务。
