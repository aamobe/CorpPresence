# 公司增强与原版液体系统的边界

普通水的灌装、倒装、纯度计算、鉴定、分类、容器估值和原版顾客收货，交给游戏原版处理。公司增强保留原版水质缓存、顾客规则和旧档水瓶数据。

公司增强等待游戏应用启动语言并加载对应的本地化表，再初始化液体功能。银血继续使用既有的成分 ID。采血、活化和反应釜属于公司配方，存储和转移沿用原版液体系统。公司逻辑用成分 ID、数量、纯度或档位判断，翻译后的名称用于显示。

本地测试版已撤掉通用液体估值补丁。若后续加入固定回收价，报价仅适用于指定公司顾客和符合条件的银血样品，原版容器估值沿用游戏规则。

原版水名错配已经通过现场日志确认。公司增强的启动改动旨在减少本模组触发名称过早初始化的机会，尚无现场证据证明测试版解决了拒收。后续验证应覆盖中英文冷启动、旧档中的普通水和大水箱，以及旧银血的读档、倒装和加工。
