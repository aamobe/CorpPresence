# 专用工作仓

在杰克逊博士的私人电话 52746 订购，固定价 800 信用点，每个存档限购一件，沿用私人订单的付款和次日配送。外壳以原版超科技储藏为主参考，采用独立 64×64 像素贴图和实心 4×4 占格。每页初始 11×14 格，创建时就有五页。

将金属锭拖到工作仓本体上升级，每次消耗 1 锭，纯度不限，五页各增 1 列和 1 行。最多四级，满级每页 15×18，外壳仍占 4×4，库存顺序和物品原格位保持。保存后重读时，先恢复页容量再放回物品。

烟草和香水页均收水培专用模组。食品与水产、银血页均收水产池适用的滤芯和饲料投喂器。

直接拖到工作仓本体时，只检查物品的首选页，不必先切页。共用物品按表格顺序选首个匹配页。普通有水的容器优先归食品与水产页。首选页放不下时拒绝放入，剩余物品留在原处。手动拖到指定页仍受该页规则约束。工作仓未满级时，金属锭拖到仓体执行升级，手动拖进锻造页可直接储存。

收纳要求玩家拥有工作仓和放入的物品。五页均可手动存放设备电源、通用机器模组和工艺用水。原版设备和物料按工艺相关性允许放入，拒绝无关物品、配送箱和工作仓本身。保留原版工作仓的设备运行和库存交互，由原版保存格位与当前选中的标签。

目标接口以本机 Steam 构建 `26525552` 的 `Assembly-CSharp.dll` 为据，SHA-256 为 `725CB999D019DFF1FF31BED353C7F9BB8D81A7605A15DE1F80F5A3A6CF7B1D05`。原版 `ShipSystemDirectory.MachineBayExt()` 提供每页库存尺寸，`MachineryTabs.AddTab` 提供标签页，`SaveManager.DecodeNodes` 在建立物品后按图节点序号恢复库存。记录的保存承诺见[存档数据模型](../存档数据模型.md)。

外壳参考为同构建 `items_tool2` 图集的 `hypertech_bay`（Sprite PathID 1348，48×48，PPU 100，中心轴点）。新图从 64×64 原生网格绘制，保留参考的顶盖、倒角和深色舱口结构。冷银灰外壳用短反光、亮边和凹槽阴影表现金属材质。验收统计为 16 种不透明颜色，3,092 个不透明像素和 1,004 个全透明像素。已核对 1×、4×最近邻图及 DLL 内嵌资源，库存形状单独使用全实心 4×4。渲染走公司物品的 Point 采样及原生倍率。

游戏内待测：从博士目录以 800 信用点下单并签收，隔日重开目录确认同档无法再买。选在香水页，把鼠笼、跑轮发电鼠笼、水产池和烟叶拖到仓体，确认分别去了食品与水产页和烟草页。再试多选拖放、普通水、指定错页和目标页已满。用金属锭升四次，确认每次五页各多一列和一行，第五次不耗锭。把物品放到新增的最右列或最下行，选中第五页后存读档，核对五个产线标签、页容量、物品格位和选中页。让一台正常供电的机器在仓内跨夜，和原版工作仓做对照。
