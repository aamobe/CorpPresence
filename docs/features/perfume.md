# 索拉纳香水生产线（0.9.9维护规则）

2026-11-07，100-Rev12。提取器不查纯度，按成分定量扣除并生成普通材料；合成机消耗两种材料。版本状态见[0.9.9记录](../releases/0.9.9.md)。

## 获取和种植

索拉纳电话「香水工艺」金卡开放，次日配送。固定价：花种220、基底油提取器2400、费洛蒙提取器1200、合成机1600、采血机400。花种滚动7天限购2颗，各设备滚动7天限购1台。

黑金会员继承金卡权限。恶意模式下索拉纳不需要另付目录申请费；基础会员订阅、到期和剧情暂停限制仍生效。相关入口为`CompanyWindow.Solana`、`Services.PlaceOrder`和`Malice.CatalogTier`。

油花基础进度42，原版基础速度8时约6晚；正常收获4份，基础用水100mL/晚。健康和原版模组影响成长及收获。花材不能种植。

油花先天「芳香物质Ⅰ」「不育Ⅲ」。不育沿用原版词条和返种流程：Ⅲ级降低返种概率，仍可能返种（没有其他返种基因时，每茬约43%概率返1颗）。移除不育后基础返种1颗，继承亲本基因。不育与多年生原版互斥，需先移除不育再移入多年生。油花再次结果基础进度21，烟草14，均保留原版多年生的产量-25%、生长速度-20%、返种-50%。多年生不先天赠送。旧V1默认不育Ⅹ种子一次降为Ⅲ；已移除的不育和其他改造等级保留，V2标记防止反复迁移。

芳香物质（复杂度4，可提取、移入、升级）Ⅰ级每份产物生成16mL含油花浆，等级按原版 rank^0.75 增长；Ⅱ级约26.9mL、Ⅲ级约36.5mL。浓效/弱效继续调整新产生的花浆。移除该基因则不产生花浆，花材固定已有的2mL油与其他杂质不变。旧花材成分不重写；旧花种一次补齐新先天词条，版本标记保存后不会恢复玩家已移除的基因。已有多年生旧花种不强行加入冲突的不育词条。

## 从花材取得含油混合液

每份花材：花浆16mL、已释放基底油2mL、fat5mL、protein5mL、物理杂质5mL、水3mL。用原版搅拌机打浆，加酒精并在至少50℃下温浸。花浆按咖啡同级每周期约15%速度处理，溶剂比例不足会损失产率；最多50%花浆转成油，其余成为植物残渣。整份花材理想总油量10mL，实际受原版搅拌和操作损失影响。

无需为本生产线额外过滤、沉淀、蒸发或达到指定纯度。原版化学反应继续生效。

## 含油液体转材料

基底油提取器不再吃花材或酒精自动出纯油。放入含油液体容器，每批只检查 corp_flower_oil 是否至少10000微升，精确扣除10000微升，产出1份「香水基底油」材料。水、酒精、花浆、残渣、酸等其他成分的数值不被机器修改。默认每晚2份，启动耗12电；模组增加批次仍逐批扣足油。剩油不足10mL则保留；无电或出料满不扣油。

例如容器原有油25mL、水90mL、酸1mL，两批后出2份材料，剩油5mL、水90mL、酸1mL。没有纯度门槛、危险成分拒收或按比例扣除混合液的步骤。

新材料ID：corp_presence_perfume_base_oil_material。它是普通CHEMICAL_SUPPLIES，不初始化液体容器、容量或水标签；每份代表10mL油成分。

## 提取物和香水

费洛蒙提取器：红档2袋普通血→1份神经活性提取物；蓝档1袋蓝血→1份费洛蒙提取物。默认每晚1批、启动8电。

香水合成机把两种材料放进同一原料格：普通提取物1份+基底油材料3份→原版神经活性香水1瓶；蓝血提取物1份+基底油材料2份→原版费洛蒙香水1瓶。默认每晚1瓶、启动6电，原版5次装和效果不变。性能模组增批次并同步耗料，效率模组省电。

## 采血

每次2电，出1袋普通血。每日第一次无伤、第二次轻伤、第三次重伤；已有重伤先阻止，每日最多3次。所有机器共享存档 CorpPresence.PerfumeBloodDraw=day:count。次日只重置次数，不治伤；读档不重置。出料满不扣电、不加次数、不伤害。

## 模组属性

物品说明和机内说明书均使用原版 LocHelper.BulletLines 列表格式，逐行显示性能、品质、效率。

- 基底油提取器：性能增加每晚处理份数；品质每+100降低20%的油成分消耗，10mL降到8mL，最低6mL；效率按原版减少能耗，最低1电。
- 费洛蒙提取器：性能增加每晚批次；品质+100每5个成功批次额外出1份提取物，最高长期+40%产量，红蓝路线分别累计并保存；效率减少能耗。
- 香水合成机：性能增加每晚瓶数；品质+100每5份基准用油材料需求抵扣1份，最高长期节省40%，血液提取物照扣；效率减少能耗。累计抵扣不会生成可取出的材料。
- 采血机：性能与品质不改变每日次数和伤害；追加模组仓支持效率省电，最低1电。模块仓追加于原库存之后，原版模块入口按面板角色定位，不改变旧血袋仓的保存位置。

品质有效值0–200。额外产量和节省进度使用机器整数标签累计（每500点兑现1份），低品质同样能逐步积累，不随机判定。仅整批成功出料、供电和消耗原料后推进进度；额外出料需要足够容纳整批的空间。

## 旧测试存档

香水线四种机器接入原有金属锭扩容：第一级3块，第二级另需6块，纯度不限，最多2级，每级增加2行。血袋提取器、合成机扩原料与成品格（4×4→4×6→4×8；6×4→6×6→6×8）；基底油提取器只扩成品格（6×4→6×6→6×8）；采血机只扩血袋格（4×3→4×5→4×7）。液体容器槽、电池槽、模组仓和旧版待取回格不扩容。沿用原有升级标签，部分交材料进度与等级读档保留。香水机器不加入电子元件省电升级名单；原版效率模组效果不变。

成品空间缓存检查扩容后的高度，满仓扩容后会重新判定空间。说明书列出操作和费用，物品说明显示当前等级及已交材料进度。

旧ID corp_presence_perfume_base_oil 保留为「旧版基底油液样瓶」，不清空或静默折算内容，可以放进提取器转换。新材料用独立ID，避免旧存档将液体标签、容量和成分恢复到新材料上。

旧机器的存储顺序和类型保留。旧提取器原料格、旧合成机液体格有物品时显示仅供取回的面板，取空后隐藏。旧瓶取出后可放进提取器。
