# 回归检查工程

每个子目录是一个独立的检查程序，直接编译 `src/` 里的真实实现，只把游戏边界换成替身。它们不进正式模组，也不启动游戏。

日常不需要逐个运行，入口脚本在上一级：

| 入口 | 用途 |
| --- | --- |
| [Check-Maintenance.ps1](../Check-Maintenance.ps1) | 完整回归，需要本地游戏程序集 |
| [Check-Portable.ps1](../Check-Portable.ps1) | 不依赖游戏的部分，GitHub 工作流运行的就是它 |
| [Check-Localization.ps1](../Check-Localization.ps1) | 本地化专项 |

各检查的覆盖范围和替身边界见[工具目录](../README.md)。

## 约定

- 一个目录一个工程，工程文件统一叫 `Checks.csproj`（少数历史目录例外）。
- 工程通过相对路径链接源码：本目录到仓库根是三层，即 `../../../src/...`。移动或拆分源文件后，要同步改这里的链接。
- 新增检查时，把它加进对应的入口脚本，否则不会被统一回归执行。
- 替身只模拟游戏边界，不复制业务逻辑；检查通过不等于游戏内验证通过。
